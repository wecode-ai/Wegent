# Wework reference plugins

Each child directory is an independently installable Core DSH plugin:

- `prompt-library-demo` adds reusable Composer prompts and references.
- `focus-board-demo` adds a persistent personal focus board.
- `sidebar-browser-panel-demo` adds a left-navigation button that opens a
  website beside the current workspace through the Wework built-in browser.
- `endpoint-watch-demo` checks a real URL in a Wework background browser page.

Install a plugin from **插件 → 管理 → Wework 插件** with:

```text
file:/absolute/path/to/reference-plugins/<plugin-directory>
```

Restart the Wework plugin runtime after install, enable, disable, update, or
uninstall operations.
