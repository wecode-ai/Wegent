# Skills 与 MCP 个人接入验证

环境：feature/plugin-skills-mcp，macOS arm64，Wework 隔离 Electron、独立 Executor/Codex home，Codex 0.153.3。写入仅使用合成 Skill 和本地测试 MCP 服务；额外只读预览 OpenAI 官方 Skills 仓库。Codex 可能发现本机共享 Skills，测试仅操作合成条目。

实现范围：复用现有“插件”入口，提供插件、Skills、MCP 三个页签。独立 Skill 从 Git、目录或 ZIP 预览后安装到本机个人目录或所选代码目录，不要求插件清单。MCP 使用 Codex 原生配置、工具发现、重载和 OAuth 接口。没有新增发布、分享或云端同步流程。Git 地址可记住在本机，不自动跟踪或更新仓库；同名安装明确拒绝覆盖。重新安装保留 Codex 对该路径的启停偏好。

| 用例     | 前置与步骤                                                    | 期望                                                  | 清理                                     |
| -------- | ------------------------------------------------------------- | ----------------------------------------------------- | ---------------------------------------- |
| 统一入口 | 插件页面切换插件、Skills、MCP；键盘左右切换                   | 页签和内容一致，插件原功能可用                        | 关闭窗口                                 |
| 本地安装 | 含 SKILL.md、脚本、参考文件的目录或 ZIP，读取并选中安装到个人 | Codex skills/list 可见，完整文件保留，可启停          | 卸载                                     |
| 冲突恢复 | 再次安装同名 Skill                                            | 明确冲突，不覆盖、不部分安装；关闭后重新打开可用      | 删除预览                                 |
| 项目安装 | 选择代码目录，在导入弹窗选所选项目                            | 仅写入所选目录 .agents/skills                         | 卸载并删除合成项目                       |
| Git 安装 | HTTPS/SSH 仓库、可选 ref；不可达地址                          | 成功可选择多个 Skill；失败保留输入并给出 Git 登录提示 | 关闭预览                                 |
| 卸载边界 | 插件内和 system Skill、路径穿越/符号链接输入                  | 不允许通过独立卸载破坏插件或越界路径                  | 删除合成文件                             |
| MCP 连接 | 添加真实本地 stdio MCP，查看工具；停用、启用、编辑、移除      | Codex 原生配置更新，状态来自真实运行时                | 移除服务器                               |
| MCP 错误 | 名称冲突、错误 URL、无效 JSON、不可达服务                     | 不写入无效配置；失败可编辑/刷新恢复                   | 移除合成配置                             |
| OAuth    | 可用的公司 OAuth MCP 服务                                     | 使用系统浏览器登录，刷新读取认证状态                  | 注销测试账户；本次未提供可用服务，待联调 |
