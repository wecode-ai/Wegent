# Wework 手机版

Wework 手机版用于从 iPhone 或 Android 手机查看和操作所选设备上的项目与会话。包含本机执行组件的 iPhone 安装包还可直接在手机上运行 Executor 和官方 Codex。访问电脑上的任务前，按[设备与云端工作](./devices.md)开启远程访问，并让电脑保持在线。

## 项目和会话管理

点击主页 **Wework ▾ → 新建项目**，选择在线执行设备，填写该设备上已存在的项目绝对目录和项目名称。支持这台手机的本机环境、云设备及已开启远程任务访问的电脑；项目和名称通过与 PC 相同的接口一次保存。电脑目录在电脑上验证，不是手机文件路径。

项目行右侧 **…** 提供 **置顶 / 取消置顶、重命名、归档项目全部聊天、移除项目**。移除需要确认，只从 Wework 列表移除，保留磁盘文件与会话。多目录项目使用同一个项目身份；不同电脑的同名项目相互独立。

会话行**左滑**会显示红色 **归档** 按钮，点击后才归档，完整滑动不会直接归档。同一时间只展开一行；上下滚动、搜索或切换设备后收起。**长按会话行**打开系统菜单，提供 **置顶 / 取消置顶、重命名、复制对话串 ID、归档**。从 **Wework ▾ → 已归档会话** 可以搜索、恢复或永久删除所选设备的已归档会话；永久删除需再次确认且不可恢复，不删除普通项目文件。归档受管工作树时，由所属执行器保存快照后清理；仍有未归档会话共用的工作树会保留，恢复会话时恢复已保存的工作树。

连接电脑时，以上操作要求同账号且目标电脑当前开启远程任务访问。关闭开关后后续请求立即被拒绝。操作失败保留原数据并显示系统错误提示；已成功写入但列表读取失败时，通过列表错误入口重试读取，不重复创建、归档或删除。

## 在这台手机上执行

App 打开后直接显示任务列表，无需先登录后端。包含执行组件的安装包会自动准备本机执行；在 **设置 → 本机执行** 查看状态或重试。未登录时隐藏 **全部 / 这台手机** 设备筛选，默认在手机上新建会话。项目、Git、会话、附件和进程属于持久本机环境；登录、退出或切换 Wegent 账号不会停止本机任务或切换本机文件。

进入 **设置 → 模型与账号 → OpenAI 账号**，点击 **使用 OpenAI 账号登录** 完成官方浏览器授权；也可明确选择 **使用设备码登录**，部分账号需先在 ChatGPT 设置中启用设备码授权。只有 Codex 确认成功后才刷新账号与模型目录。

在 **设置 → 模型与账号 → 添加模型** 配置 API Base URL、模型 ID 和 API Key（无需鉴权的服务可留空），可选填显示名称。当前仅支持 **Responses API**。**测试连接** 会发送真实工具调用请求；**保存模型** 后可在聊天中选择。密钥保存在本机安全存储中。

保存模型或启动 OpenAI 登录前，会显示任务数据共享确认。点击 **同意并继续** 后才执行保存或登录；取消会保留当前输入。模型页面和 **设置 → 隐私 → 隐私政策** 均可打开应用内完整[隐私政策](./mobile-privacy.md)，支持离线阅读及中英文切换；“查看公开版本”才访问外部网址。消息、附件、所需文件和工具结果可能发送至你选择的模型服务；本机执行不代表模型推理也在设备上完成。

如需云设备或后端模型，进入 **设置 → 登录 Wegent**，在登录页面配置后端地址并授权。登录后才显示设备筛选。设置使用独立全屏页面，右上角 **×** 关闭；新聊天页面沿用原布局。

升级时会继承旧本机环境；如果发现多个旧环境，进入 **设置 → 本机执行** 选择保留的环境。切换会先停止当前执行，但不会合并或删除任何环境的文件与会话。

本机执行目前限于带执行组件的 iPhone 真机安装包；Android 继续支持远程设备。手机本地 Linux 环境不支持只读或工作区权限沙盒，需明确选择 **完整访问**，访问范围仍受 iOS App 沙盒约束。已有受限权限选择不会被自动提升。

iOS 使用系统短时后台额度，让前台发起的任务在切后台后尽力继续。后台额度由系统决定，不能保证 Codex 长任务在后台或锁屏后持续完成；需要持续运行的长任务请保持 App 在前台。额度耗尽时会中断后台任务并明确提示，但不会因为后台额度耗尽而取消仍在前台运行的任务。划掉 App 会停止执行。返回前台后从执行器保存的转录恢复会话，不能将进程终止前的旧审批请求当作仍然有效。

## 主页入口

打开应用后，主页直接显示 **置顶 / 项目 / 任务**，底部 **向 Wework 提问** 发起新会话。

| 入口               | 操作                                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------------------------ |
| 左上角菜单         | 打开侧边栏；点击 **Wework** 返回主页，点击账户旁设置进入连接设置；头像连接失败标记可点击重试           |
| 顶部 **Wework ▾**  | 打开更多选项：**新建项目**、**已归档会话**、**设置**、**显示全部设备**；项目创建取决于当前设备是否支持 |
| 右上角放大镜       | 按会话标题、项目名或设备名筛选当前范围内的会话；点击右上角关闭按钮退出搜索并清空查询                   |
| 顶部设备条         | 登录 Wegent 后显示；点击 **全部** 查看在线设备的会话，或点击设备名缩小范围                             |
| **置顶**           | 点击展开或收起已置顶会话；沿用电脑端保存的置顶状态与顺序                                               |
| **项目**、**任务** | 展开或收起分组；点击会话标题进入聊天，下拉列表手动刷新                                                 |

设备条默认显示在线设备，可独立左右滑动；向上滚动主页列表时，设备条随列表一起滚出屏幕。选择 **Wework ▾ → 显示全部设备** 可查看离线设备状态；离线设备不能作为新会话的执行设备。

同名项目按设备和工作区分别显示。项目旁的灰色文字来自实际工作区名称或目录名；点击项目名称展开会话，点击右侧新建图标在该工作区发起会话。

## 发起与继续会话

点击主页底部的 **向 Wework 提问** 进入新会话；页面切换完成且输入框可用后，会自动聚焦并弹出键盘，可直接输入。在输入框上方选择设备和项目；选定工作区后，可选择在原工作区运行或创建 Git 工作树。新建入口需要当前范围内有支持创建任务的在线设备。

选择项目后，点击 **在本地工作 → 新建工作树**，再点击分支行打开 **启动分支**，可搜索并选择已有分支。默认从当前分支启动；发送首条消息时才创建独立工作树，不会切换原目录的分支。后续消息继续使用该会话的工作树。切换项目、设备或新建会话后会重置启动方式和分支选择。

工作树能力、仓库和目录写入权限由所选工作区所在设备检查，与 PC 版保持一致。不满足条件时，**新建工作树** 会显示原因；读取失败可重新检查或重试分支加载，仍可选择在原工作区运行。手机本机执行与已授权远程设备使用相同的工作树协议。

点击输入框展开工具栏，输入内容后点击向上箭头发送。已有会话使用 **跟进** 输入框继续原会话；运行时点击方形停止按钮取消当前回复。左上角返回按钮回到列表，聊天页右上角的新建图标可开启另一段会话。

## 语音输入

点击输入框中的麦克风开始本地语音输入。识别期间输入框切换为语音条，显示实时音量、取消、停止和发送操作。点击停止后，最终文字写入输入框供发送前检查；点击发送会停止识别并直接提交识别结果。取消会丢弃本次结果。键盘已收起时启动语音不会重新弹出键盘。

iOS 使用系统提供的本地语音识别，不需要在 App 内另外下载识别模型；首次使用需允许麦克风和语音识别权限，并依赖当前系统语言包。Android 使用系统本地识别，要求 Android 13 或更高版本；中文离线语音包未安装时会启动系统下载入口。设备缺少本地识别能力或权限被拒绝时，输入框会显示可重试的错误。

## 回答问题

会话出现问题卡片时，点击 **回答问题**，选择选项或填写自定义回答，再点击 **发送**。普通问题的回答会提交给原任务等待中的问题；异步问题允许任务继续运行，运行中提交的回答会作为指导送达，任务停止后提交则会继续原会话。

**跳过** 的含义取决于问题类型：普通问题会取消当前任务回复，并结束该回复中待处理的问题；MCP 表单问题会向工具提交空回答，结束该表单请求。点击右上角关闭按钮仅收起面板，问题仍然等待处理。

只有执行设备确认接受后，卡片才显示 **已回答** 或 **已跳过**。提交失败会保留问题与已填答案，并显示错误和重试入口；刷新会话不会重新打开已接受的回答。需要打开外部页面的授权请求会提示在电脑端完成。

## 模型、权限与附件

- **模型**：展开输入框，点击蓝色模型图标。面板标题显示完整模型名称、当前智能等级和高级设置箭头；支持推理等级的模型可通过滑块调整，三档模型显示三段，五档模型显示五段。拖动滑块不会触发聊天页返回手势。点击标题进入 **高级**，再点击 **模型**、**智能** 或 **速度** 行，在弹出菜单中选择。**智能** 只显示当前模型支持的推理等级；支持速度设置时，可选择 **标准** 或 **快速**。选中后菜单收起并显示当前值，设置用于新建会话和后续发送；切换模型会按新模型能力调整选项。模型目录加载失败时，可在高级面板点击刷新。
- **权限**：展开输入框，点击权限图标，选择 **只读**、**工作区** 或 **完整访问**。权限控制任务在执行设备上的操作范围。
- **附件与模式**：点击输入框左侧 **+** 添加照片或文件，也可选择当前设备提供的技能、计划或追求目标模式。

切换模型面板不会清空尚未发送的草稿。设备、项目和会话的归属与电脑端一致，切换列表筛选不会把已有任务迁移到另一台设备。

## 文件与变更预览

会话页右上角的文件夹图标 **浏览工作空间文件** 打开当前目录；尚未确定可访问工作目录时不可用。
点击回复中的文件链接、工具详情的路径、附件或展开后的变更文件，可打开只读预览，并查找、定位或
通过系统面板分享。**最近** 仅保留当前登录会话内的文件与阅读位置，关闭预览不会清空聊天草稿。
详细入口、文本截断说明和格式限制见[移动端文件预览](./mobile-file-preview.md)。切换后端账号会清除远端文件的预览缓存与最近记录，本机文件的预览和阅读位置会保留。

## iOS 与 Android

支持液态玻璃的 iOS 系统使用原生玻璃按钮和面板；开启系统的“降低透明度”后使用清晰的实色表面。Android 使用原生面板、圆角、边框与触控反馈，两端保留相同的功能入口，并适配安全区和键盘。
