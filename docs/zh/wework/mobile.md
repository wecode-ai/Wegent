# Wework 手机版

Wework 手机版用于从 iPhone 或 Android 手机查看和操作已连接设备上的项目与会话。任务仍在所选设备上运行，手机不运行执行器。访问电脑上的任务前，按[设备与云端工作](./devices.md)开启远程访问，并让电脑保持在线。

## 主页入口

打开应用后，主页直接显示 Wework 的设备、项目和会话。

| 入口               | 操作                                                                                   |
| ------------------ | -------------------------------------------------------------------------------------- |
| 左上角菜单         | 打开侧边栏；点击唯一的 **Wework** 入口返回主页，点击底部账户进入连接设置               |
| 顶部 **Wework ▾**  | 打开更多选项：**新建项目**、**设置**、**显示全部设备**；项目创建取决于当前设备是否支持 |
| 右上角放大镜       | 按会话标题、项目名或设备名筛选当前范围内的会话；点击右上角关闭按钮退出搜索并清空查询   |
| 顶部设备条         | 点击 **全部** 查看在线设备的会话，或点击设备名缩小范围；左右滑动可查看其他设备         |
| **置顶**           | 点击展开或收起已置顶会话；沿用电脑端保存的置顶状态与顺序                               |
| **项目**、**任务** | 展开或收起分组；点击会话标题进入聊天，下拉列表刷新                                     |

设备条默认显示在线设备，可独立左右滑动；向上滚动主页列表时，设备条随列表一起滚出屏幕。选择 **Wework ▾ → 显示全部设备** 可查看离线设备状态；离线设备不能作为新会话的执行设备。

同名项目按设备和工作区分别显示。项目旁的灰色文字来自实际工作区名称或目录名；点击项目名称展开会话，点击右侧新建图标在该工作区发起会话。

## 发起与继续会话

点击主页底部的 **向 Wework 提问** 进入新会话；页面切换完成且输入框可用后，会自动聚焦并弹出键盘，可直接输入。在输入框上方选择设备和项目；选定工作区后，可选择在原工作区运行或创建 Git 工作树。新建入口需要当前范围内有支持创建任务的在线设备。

点击输入框展开工具栏，输入内容后点击向上箭头发送。已有会话使用 **跟进** 输入框继续原会话；运行时点击方形停止按钮取消当前回复。左上角返回按钮回到列表，聊天页右上角的新建图标可开启另一段会话。

## 回答问题

会话出现问题卡片时，点击 **回答问题**，选择选项或填写自定义回答，再点击 **发送**。普通问题的回答会提交给原任务等待中的问题；异步问题允许任务继续运行，运行中提交的回答会作为指导送达，任务停止后提交则会继续原会话。

**跳过** 的含义取决于问题类型：普通问题会取消当前任务回复，并结束该回复中待处理的问题；MCP 表单问题会向工具提交空回答，结束该表单请求。点击右上角关闭按钮仅收起面板，问题仍然等待处理。

只有执行设备确认接受后，卡片才显示 **已回答** 或 **已跳过**。提交失败会保留问题与已填答案，并显示错误和重试入口；刷新会话不会重新打开已接受的回答。需要打开外部页面的授权请求会提示在电脑端完成。

## 模型、权限与附件

- **模型**：展开输入框，点击蓝色仪表图标。支持推理等级的模型可通过滑块调整；点击模型名称进入 **高级**，再点击 **模型**、**智能** 或 **速度** 行，在弹出菜单中选择。**智能** 只显示当前模型支持的推理等级；支持速度设置时，可选择 **标准** 或 **快速**。选中后菜单收起并显示当前值，设置用于新建会话和后续发送；切换模型会按新模型能力调整选项。模型目录加载失败时，可在高级面板点击刷新。
- **权限**：展开输入框，点击权限图标，选择 **只读**、**工作区** 或 **完整访问**。权限控制任务在执行设备上的操作范围。
- **附件与模式**：点击输入框左侧 **+** 添加照片或文件，也可选择当前设备提供的技能、计划或追求目标模式。

切换模型面板不会清空尚未发送的草稿。设备、项目和会话的归属与电脑端一致，切换列表筛选不会把已有任务迁移到另一台设备。

## 文件与变更预览

会话页右上角的文件夹图标 **浏览工作空间文件** 打开当前目录；尚未确定可访问工作目录时不可用。
点击回复中的文件链接、工具详情的路径、附件或展开后的变更文件，可打开只读预览，并查找、定位或
通过系统面板分享。**最近** 仅保留当前登录会话内的文件与阅读位置，关闭预览不会清空聊天草稿。
详细入口、文本截断说明和格式限制见[移动端文件预览](./mobile-file-preview.md)。

## iOS 与 Android

支持液态玻璃的 iOS 系统使用原生玻璃按钮和面板；开启系统的“降低透明度”后使用清晰的实色表面。Android 使用原生面板、圆角、边框与触控反馈，两端保留相同的功能入口，并适配安全区和键盘。
