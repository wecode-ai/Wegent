# 插件认证与安装的写入协调

认证、退出登录、安装、更新、卸载及设备安装状态写入使用 Redis 互斥，
不再通过 `SELECT ... FOR UPDATE` 锁住 `users.id`。发布和设备注册的锁策略不在本次改造范围内。

## 共享协议

Python 与已迁移的 Rust 自动更新接口必须使用同一协议：

- 锁键为 `wegent:plugin-write:{user_id}`，值为随机的 32 位十六进制 token。
- 锁冲突等待上限为 3 秒，租约 30 秒。Python 每 10 秒续租；Rust 将整个操作限制在 20 秒内。
- 锁覆盖用户的插件业务域，因为自动认证策略、连接迁移与安装状态存在跨插件约束。
  同一事务需要多个用户时按用户 ID 升序获取锁。
- 续租和释放必须比较 token。Redis 不可用时拒绝写入，不回退到无锁执行。
- 锁保持到最外层事务提交、回滚或关闭；保存点结束不会释放锁。

仅检查 Redis 所有权无法防止检查后暂停的旧进程提交。因此获取租约后，
先读取现有 `kinds` 表中该用户 `ConnectorAuthPolicy` 的 `$.spec.revision`，
再读取安装、连接和迁移等业务状态。策略的 namespace 为 `plugin-auth`，name 为 `account`。
首次使用时通过独立短事务物化原有默认策略 `enabled=true, revision=0`；
已有策略不使用额外连接，也不会覆盖用户关闭自动认证的选择。

业务事务的最后一条 SQL 以主键、完整策略身份及旧 revision 为条件，原子递增 revision，
受影响行必须为 1，否则整个事务回滚。所有插件写事务共用这个真实业务父版本，
因此首次安装即使并发插入不同 ID 的安装和 ZIP 记录，也只有一个事务可以提交；
退出登录修改策略后，旧自动认证请求同样无法插入新的迁移意图并提交。
安装记录自身及账号连接记录也使用 revision CAS，安装版本号 `version` 不承担并发校验。
旧策略和安装记录缺少 revision 时从 0 开始，非法值拒绝写入。

后继事务提交后，旧版本事务一定失败；后继仅取得租约尚未提交时，CAS 仍可能让其中任意一方先提交，
另一方冲突回滚。这是乐观串行提交，不以获取 Redis 租约的时间决定提交顺序。
这里保留正常 DML 的事务行锁；按主键定位业务记录，不使用显式查询锁，也不保证完全没有锁等待。

Python 的请求 Session 必须在第一条 SQL 前调用 `configure_plugin_session`，
HTTP 使用共享 `get_plugin_db` 依赖，以 READ COMMITTED 读取取得租约后的最新状态。
Rust 在目录预加载之前保存父版本，并在固定连接的业务事务开始时重查该版本，提交时再做 CAS，
避免把连接外预加载的旧状态带入新版本。外部 OAuth 和设备网络请求放在写事务之外。
保存点回滚会恢复事务内预期的策略版本，只有根事务结束才释放租约。

## 故障与部署

客户端错误为 HTTP 503 的 `plugin_write_busy`、`plugin_write_unavailable` 或
`plugin_write_lease_lost`、`plugin_write_conflict`；认证 broker 通过相同错误码返回拒绝结果。
冲突后必须回滚整个事务，再重新读取业务状态；不得盲目重放 OAuth 等外部副作用。
Python 的 Redis 使用独立短超时且不重试的客户端。首次创建默认策略使用独立连接池，
每个进程最多额外占用 4 个 MySQL 连接，获取连接最多等待 1 秒。
Rust 复用 Breeze 连接池，获取租约和首次物化策略分别限制在 3 秒内，释放限制在 500 毫秒内。

不新增表或业务列。部署前执行 Alembic `upgrade head`，仅为上述真实策略身份增加唯一表达式索引
（MySQL 8.0.13 及以上），
确保首次物化不会产生两个父版本。索引不限制其他 Kind 或不同来源的同名插件。
若历史数据存在重复策略，迁移会停止并要求核对，避免静默丢弃用户配置。
旧进程不参与 Redis 协议，因此切换时应排空旧版插件写请求，再同步启用新版 Python、Rust 写入口；
不能依赖新旧写进程混跑时的互斥。回滚代码或删除索引前同样需要排空新版写请求。

真实 MySQL、Redis 并发回归由 `test-plugin-auth-mysql` CI 任务运行，
覆盖用户行锁不阻塞退出、同时注册凭证、卸载与认证交错、过期请求提交、
首次安装的 ZIP 完整回滚、策略缺行、退出与自动认证交错及 OAuth 刷新。
