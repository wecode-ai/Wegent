# 代码工作台

## 使用顶部标签页

Wework 桌面版使用顶部标签页承载任务、项目空间、智能体和其他功能页面。点击侧边栏链接时，页面会在当前标签页内切换；只有点击顶部 **+** 或使用标签页菜单中的明确新建操作时，才会创建新的标签页。

首次打开主窗口时会创建任务、项目空间和智能体三个默认标签页。每个标签页都是独立的工作实例：两个任务标签页分别保留自己的对话和未发送草稿，两个项目空间标签页分别保留自己的项目与路由，两个智能体标签页分别保留自己的页面状态。切换标签页不会把另一个标签页的内容同步过来。

标签页较多时，标签列表会水平滚动，顶部 **+** 和最右侧的反馈按钮始终保持可见。标签页也可以通过右键菜单移动到独立窗口。移动成功后，原窗口会移除该标签页；新窗口只包含被移动的标签页及其状态，不会再次创建三个默认标签页。创建新窗口失败时，原窗口中的标签页保持不变。

任务页与插件、云端工作等功能页面共用标题栏下方的全宽桌面内容容器。因此在同一标签页内切换页面时，左侧栏的位置与外观保持一致，不会因页面类型不同而发生位置跳动。页面仍可在该容器内绘制各自的内部外观。

## 在项目空间和运行任务之间往返

如果运行任务已经关联到项目空间中的具体任务，可以在运行任务的 Environment 信息中点击任务名称，打开对应项目空间标签并定位到该任务详情。项目空间任务详情的“本地执行”区域会列出关联的 Wework 运行任务；点击其中一条记录可以返回对应的运行任务标签。两次跳转都会复用已有标签页，并保留项目空间或运行任务的可恢复路由。

## 使用项目侧边栏

点击项目名称可以展开或收起该项目的运行任务。收起的项目显示闭合文件夹图标；展开后图标会改为打开的文件夹，方便识别当前展开状态。

## 拖拽任务分屏

从侧边栏拖拽任务到工作台中的上、下、左、右区域，可以在对应方向创建任务分屏；拖到中央区域则会替换当前区域的任务。指针进入工作台后，侧边栏会停止任务排序和自动滚动，避免侧边栏的拖拽效果抢占分屏操作。将指针移回侧边栏后，可以继续调整任务顺序。

## 开始新任务

新任务页使用紧凑的建议按钮帮助选择任务方向。点击一个方向后，可以继续选择更具体的提示；选中的提示会写入下方输入框，仍可在发送前编辑。

项目选择、消息输入、快捷短语和模型选择位于同一个输入面板中。输入框获得焦点时会显示蓝色边框，项目、附件、快捷短语和模型设置不会因新任务页的简化布局而减少。

## 使用弹窗快速输入

Wework 弹窗在没有运行任务时使用固定高度的紧凑输入面板。输入内容超过三行后，文本会在输入框内部滚动，底部的附件、模型和发送控件保持在弹窗可视范围内。

## 文件与终端

右侧工作区用于浏览项目文件、预览内容和审核变更。多目录项目会在文件标签中显示文件夹选择器；切换文件夹只改变文件树和预览根目录，不会改变任务、终端或对话使用的执行目录。

助手回复中的本地文件和目录链接可以直接在文件标签中打开。文件链接可以定位到指定代码行；目录链接会将该目录设为文件树根目录。在 macOS 桌面版中，文件标签的“打开”和“打开位置”操作同时支持文件与目录。

使用 `Command+J` 打开或关闭底部工作区面板。打开面板不会自动创建新终端；已有终端会按任务保留，切回任务时直接恢复。

点击底部标签栏的 **+**，可以根据当前设备能力选择 **Terminal**、**IDE** 或 **桌面**。Terminal 从当前项目目录启动，Worktree 任务从对应工作树启动；IDE 在系统默认浏览器中打开；桌面能力可用时在 Wework 内置浏览器中展示。

排查切换任务后终端未重绘时，前端日志会记录终端类型、任务与会话标识、激活阶段、xterm 行列数、容器尺寸和隐藏状态；不会记录终端输出、命令或工作区路径。

排查 `[Terminal connection failed]` 时，按同一个会话标识串联 `Local terminal start`、`Local terminal connection`、`Tauri local terminal attach` 和 `Local terminal close` 日志。日志会记录宿主进程、子进程、任务、工作区路径、连接阶段和关闭原因，从而区分输出监听、退出监听、原生 attach、会话不存在和主动关闭等情况。上述日志不记录终端输入、输出、执行命令或环境变量内容。

## 展开右侧工作区

打开右侧工作区后，点击标题栏中的 **展开面板**，可以让文件、预览或审核内容占满主工作区。展开文件、浏览器等非聊天工作区时会隐藏任务输入框；展开临时聊天时只保留临时聊天自己的输入框。展开状态会按对话保存。

在展开状态下仍可收起左侧栏，使窗口只显示右侧工作区。点击右上角的 **恢复面板**；已有对话时，也可点击展开工作区底部的 **最近一条**，返回对话与右侧工作区并排显示的布局。关闭右侧工作区或关闭其最后一个标签时，展开状态也会自动结束。

## 查看执行过程

任务运行时，对话会显示正在使用的工具和当前进度。已完成的工具调用会折叠为摘要，可以展开查看命令或修改过的文件。

## 浏览长对话

当对话内容超过当前视口时，消息区左侧会显示历史发言导航。导航固定在对话视口中央，不会随消息内容滚动；点击标记可跳转到对应发言，将指针悬停在标记上可预览用户请求和助手回复摘要。

## 切换对话与恢复位置

切换对话时，桌面工作台会保存运行状态、最近消息、右侧工作区标签和面板状态；切回后会立即恢复离开时的工作区。文件标签会恢复离开前选中的文件及其实际目录，包括从助手消息打开的工作区外绝对路径；审核标签会恢复所选审核范围和已经加载的 Diff。普通对话不会保留隐藏的完整页面 DOM，以限制长对话带来的 WebView 内存增长。

包含运行中 Terminal 或 Wework 内置浏览器的对话页面会保持挂载。Terminal 进程、标签和输出缓冲会继续保留，内置浏览器的页面、地址和标签状态也会保持；关闭对应资源后，页面即可释放，仅保留可恢复的面板状态。隐藏对话不会响应当前对话的快捷键或浏览器打开事件。

首次打开的对话会定位到最新消息。已经停留在底部的对话切回后仍保持底部；如果之前浏览到历史消息，则恢复与底部的相对距离。长对话只挂载视口附近的消息，并复用已测量的消息高度，减少滚动时的 WebView 内存增长。

消息、滚动位置和消息高度缓存都有数量上限。归档任务时会立即移除该任务的缓存；再次打开已被缓存淘汰的任务时，Wework 会从本地运行时重新读取完整记录。

## 使用回复中的选中文本

在助手回复中选择一段文本后，可以将其添加到当前对话输入框，或在侧边栏中基于该文本继续提问。回复仍在流式输出时也可以使用这些操作；后续内容更新不会关闭已经打开的文本操作菜单。

## 审核本轮变更

支持的 Git 任务完成后，助手消息下方会显示本轮文件变更，包括文件数量和增删行数。点击 **审核** 可查看完整 Diff、筛选文件、切换自动换行和复制 `git apply` 命令。

审核内容从执行任务的设备读取，因此设备需要保持在线。

## 撤销本轮变更

点击 **撤销** 后，Wework 会先检查反向补丁能否安全应用。后续修改与本轮内容冲突时，工作区不会被强制覆盖。撤销只处理当前轮产生的变更。

## 完成 Git 工作流

在提交或创建 Pull Request 前建议：

1. 审核所有变更文件。
2. 运行与改动相关的测试和格式检查。
3. 检查工作区是否包含临时文件或敏感信息。
4. 确认提交信息和目标分支。
5. 推送分支并创建 Pull Request。

归档 Worktree 任务前，先处理未提交修改；强制归档会移除对应工作树。
