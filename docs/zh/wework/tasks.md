# 与 AI 协作

## 描述任务

| 模型、推理与权限 | 输入区选择模型及其支持的推理等级；点权限图标切换模式       | 字段随模型/设备能力变化；权限模式不是应用登录授权                              |
| 语音输入         | 麦克风 → 开始录音 → 停止并识别 → 检查文字 → 发送           | 首次准备模型和系统麦克风权限，详见下文                                         |
| 排队、引导与暂停 | 运行时使用输入区的发送动作；需要中断当前回复时点暂停       | 消息排队、执行任务队列和持续目标是不同状态                                     |

### 持续目标的状态与控制

创建 Goal 后，输入区附近显示目标条及状态。悬停或聚焦目标条会显示 **编辑目标**、**删除目标**；目标条右侧按当前状态显示 **暂停目标** 或 **开始目标**。先暂停持续目标，再检查是否还需暂停当前回复；仅停止一轮回复不能视为已暂停持续目标。

目标可能处于运行、暂停、阻塞、预算/用量受限或完成状态。预算耗尽、工具失败、断开连接都不是完成证明；根据准确状态处理条件后再选择继续。删除目标与删除对话也不是同一操作。

### 模型过载与额度恢复

本地 Codex 任务遇到模型过载时，会按 10 秒、30 秒、2 分钟、5 分钟的间隔自动重试，界面显示倒计时。重试延续原会话和模型，保留已完成的工具执行记录。

订阅额度耗尽后，任务进入等待队列并释放执行名额。输入区显示额度恢复倒计时；到期后，Wework 重新检查额度并使用原模型继续，包括因额度暂停的持续目标。没有明确恢复时间时，每分钟检查一次。等待记录会保存在本机，重新打开 Wework 后继续等待；应用关闭期间不会执行。

点击输入区的 **取消自动继续** 可停止自动恢复。暂停、修改或删除持续目标，以及发送新的任务输入，都会使原等待失效。账号、模型配置或会话已变化时，需要重新发起执行。任务自身的预算耗尽仍需调整预算后继续。

### 会话内交互

这项能力也适用于查找会话、恢复归档、选择操作对象等场景。独立任务属于会话；可以直接让 AI 查找刚刚误操作的任务，查询包含已归档的候选，不必先提供完整标题或操作时间。在 **Codex 会话输入区** 提出需求后，直接使用回复中的按钮、列表或表单。界面根据需求生成；找回归档会话时，从候选列表点击 **恢复归档**，成功后再点击 **打开会话**。永久删除与归档不同，恢复归档工具只处理仍在归档中的会话。没有对应操作工具时，可提供按钮跳转到已有功能入口。操作仍遵循现有权限，跳转本身不会执行操作。

界面高度随内容变化，已保存的交互状态在再次打开会话时恢复。鼠标位于卡片内时也可上下滚动会话；文本框等内容可滚动时先在内部滚动，达到边界后继续滚动会话。需要更多空间时使用 **展开**，完成后可以收回到消息内。此能力面向有个人控制权限的 Codex 会话，不向委派执行提供额外权限。

<a id="personal-schedules"></a>

### 个人定时任务（已安排）

在 **Codex 会话输入区** 描述你想完成的操作，例如“帮我创建一个今天 18 点执行的任务”。AI 可以根据当前场景在消息中生成交互界面，填写已知信息，缺失内容由你在表单中补充。提交后调用真实工具并在原位置显示结果。新建定时任务沿用当前会话的模型、工作目录和执行配置，执行时需保持所属设备上的 Wework 运行。

<!-- ui-source: src/features/automations/AutomationsPage.tsx -->

1. 打开 **左侧栏 → 已安排**，用搜索筛选已有计划，或点击创建。
2. 填写名称和任务说明。选择每次运行创建新任务，或继续已有的已固定任务；需要持续完成时启用持续目标并明确目标。
3. 在运行位置选择本地/云端、设备、项目、模型与支持的推理等级。执行目录、账号和插件以选中设备为准。
4. 选择工作日、每天、每周、自定义或仅一次；按表单设置执行时间和自定义间隔。通知可选所有运行、仅需要关注或不通知。
5. 保存后检查计划状态。编辑后需要再次保存；通过运行记录打开实际工作查看结果，不能把计划已保存等同于运行成功。
6. 暂时不运行时停用计划；删除时核对确认。个人计划、项目看板自动化和分身日历各有独立入口，不要互相替代。

使用云端模型的个人定时任务在每次触发（包括手动运行）时，会重新校验模型访问权限并读取当前云端连接的凭据。登录令牌续期后，无需重新创建计划；新建任务和继续已有任务均使用当前凭据。若登录已失效、模型已删除或访问权限已撤销，本次运行会失败，请检查云端连接和模型权限后重试。

一条有效的任务说明通常包含目标、范围、约束和验收方式。例如：

```text
为用户设置页增加语言选择：
- 支持中文和英文；
- 复用现有设置组件；
- 选择后立即生效并持久化；
- 补充相关单元测试。
```

复杂任务可以先要求 AI 调研并给出方案，确认后再实施。

### 语音输入

点击任务输入框底部的麦克风开始语音输入。首次使用时，按提示准备语音识别模型，并允许系统麦克风权限；也可以在 **设置 → 通用 → 语音输入** 中准备模型。

选择模型时，日常语音输入可先选 **INT8（轻量版）**，下载和内存占用更少。如果识别错字较多，可试用 **FP32（完整精度版）**；它保留完整的 32 位浮点精度，下载和内存占用更大。设置页和首次准备弹窗中均有选择说明。

语音输入处于请求麦克风、录音、转写或结果反馈状态时，输入框左侧的其他操作会隐藏，保留语音控件。结束或取消语音输入后，这些操作会恢复；切换会话也会退出当前语音输入。

录音结束后点击停止并识别，识别文字会插入开始录音时的输入位置，供你检查、编辑后发送。取消录音不会修改草稿。如果录音期间修改了草稿，识别结果会保留，请点击 **插入文字** 放到当前光标位置。

语音输入复用 DSH 官方插件；默认的本地识别模型下载完成后可在设备上转写。

### 编辑 Markdown 和表格

粘贴的 Markdown 会在输入框中直接显示为可编辑内容，发送后的消息也会渲染表格、列表、粗体和代码。使用 `Shift+Enter` 换行，在表格中使用 `Tab` / `Shift+Tab` 切换单元格。

将指针移到消息中的表格上，可以复制该表格的 Markdown 或展开查看；按 `Esc` 关闭展开视图。点击输入框中的 HTTP/HTTPS 链接可以打开链接操作，发送后点击链接会按浏览器偏好打开。粘贴链接后追加的文字保持独立，不会修改链接地址。

## 添加上下文

你可以在输入区添加文件、图片、代码位置和应用快照。应用快照会截取当前前台窗口，并在获得系统辅助功能权限时附带窗口文本。

发送本地图片后，Wework 会在消息中保留图片预览。关闭并重新打开 Wework 或切换到其他会话后，返回原会话仍可查看该图片；如果原始本地文件已被删除，预览将无法恢复。

输入 `/` 可以选择可用 Skill。插件安装后，其 Skills、命令或工具会出现在对应任务能力中。

在输入框中输入 `@` 并选择对话或 Issue 后，会插入引用胶囊。发送前点击胶囊，或聚焦后按 Enter/空格，可以在当前任务窗格打开被引用的对话，或打开/复用对应项目空间看板并定位到该 Issue；未发送的草稿会保留。发送后，点击用户消息中的同一引用也会执行相同跳转。引用地址无法解析时不会跳转；地址可解析但目标已删除或无权访问时，Wework 会先打开对应的任务或看板，再显示加载错误或不可访问状态。

对话引用保留已完成的可见助手回复。工具执行记录晚于回复更新时，不会仅因记录顺序将回复当作过程文本丢弃；显式过程消息和仍在生成中的文本仍按其消息阶段处理。

## 从任务侧栏修复 PR

点击任务左侧的 PR/MR 状态，在异常状态弹窗中选择 **让 AI 继续修复**。任务正在运行时，修复要求会作为追问引导当前回复；任务空闲时，会在原会话中启动下一轮。如果当前回复恰好在点击后结束，修复要求会转为下一轮消息。发送失败时会显示错误，可以再次点击发送。

## 将对话加入项目空间看板

运行任务或私人会话的标题与绑定 Issue 的标题独立。无论从任务、Issue 详情还是协作入口发起执行，后续会话标题更新都不会修改已有 Issue 的标题；需要改名时，请在 Issue 详情中编辑。

开启实验性功能后，可以通过输入框的 **+** 菜单选择 **项目空间**。即使新任务尚未发送第一条消息，选择空间后也会打开 **加入「项目空间名称」** 弹窗，可以选择 **新建看板任务** 或 **关联已有看板任务**。确认后先保存选择，发送第一条消息时才创建卡片或关联所选 Issue；取消弹窗会保留原有选择。再次选择当前空间可以更改关联方式或目标 Issue。

选中的空间会以 **加入看板 · 项目空间名称** 显示在输入框底部，让你在发送前确认本次对话将进入哪个看板。本地项目设置的自动加入空间也会通过同一控件明确显示，默认在发送首条消息后新建看板任务。

对于已经启动的任务，可以在右侧 **环境** 面板中选择 **关联项目空间**，将当前项目或当前任务关联到本地、云端项目空间，或者在空间中快速新建任务。选择本地空间时操作保存在当前设备；选择云端空间时使用云端协作数据。

在协作空间中新建 Issue 时，标题和内容至少填写一项即可。只填写内容时，Wework 会将完整内容保存在描述中，并按普通任务的标题规则自动生成标题；如果同时填写标题和内容，则保留手动输入的标题。

在 Issue 详情中选择 **让 AI 帮我处理** 后，可以在任务输入框中选择本地项目、工作区或工作树以及分支，再创建与当前 Issue 关联的本地执行任务。项目空间与本地代码项目是两类独立资源；任务创建成功后，Wework 会在当前设备上记住该项目空间最近使用的本地项目和工作区。下次从同一项目空间创建任务时会自动预选，用户临时改选并成功创建任务后也会更新这组映射。该映射不会同步到其他设备。

Issue 已有关联任务时，详情页的 **关联任务** 区域会直接展示全部运行中任务和最近两个任务。存在更多历史任务时，可以通过 **展开** 和 **收起** 查看，不需要先进入单独的“查看任务”界面；继续创建任务的入口位于该区域标题旁。

任务已经关联看板后，可以在输入框上方的任务摘要中选择 **更改看板关联**，再选择目标项目空间。支持更改关联时，项目列表刷新或暂时没有选项不会隐藏该入口；选项加载后可以继续选择。Wework 会让你选择：

- **新建看板任务**：使用当前任务标题和执行状态创建卡片并建立关联。
- **关联已有看板任务**：按任务编号或标题搜索目标看板中可编辑的卡片，并把当前任务关联到该卡片；已有卡片的状态保持不变。

如果目标项目空间与当前看板不同，Wework 会先显示移动确认。确认后，当前运行任务只保留一个用户选择的看板关联；原看板卡片继续保留，但不再关联该运行任务。新建的卡片会根据当前任务状态进入相应列，例如已结束且等待确认的任务进入 **待验收**。

### 查看看板任务进展

看板卡片的关联任务进展不会重复显示运行时任务标题。任务执行中，第一行显示最新 AI 文本或思考状态，第二行通过短竖线缩进显示最近一次工具或编辑操作；PR/MR 状态作为右侧操作展示。任务停止后，卡片只显示最后一轮回复的最后一个非空行，不会回退到更早轮次。未读卡片使用清晰的蓝色强调背景和边框，并保留未读标记；打开任务后会恢复普通卡片样式。

点击卡片即可打开轻量任务界面，不会离开当前看板。浮层默认展示最新一轮用户消息和 AI 回复，并复用任务会话中的思考、工具调用和文件编辑展示；内容较长时在会话区域内滚动，顶部的 **加载更早记录** 可以继续向上读取历史。底部输入框默认保持一行，点击后展开并显示任务会话已有的快捷短语等操作；输入期间浮层会固定显示，点击右上角关闭按钮退出。一个看板任务同时运行多个任务时，浮层先列出每个任务的摘要；选择其中一个任务后，浮层会只显示该任务的进展。需要进入完整任务页时，使用卡片右下角仅在当前卡片悬停或聚焦时出现的跳转按钮；其他卡片不会同时显示该按钮。

### 首次创建项目并交给本机助手

首次进入协作空间且尚未创建项目时，Wework 会展示一条完整的入门路径：创建项目、创建 Issue、交给助手执行、查看并验收结果。点击 **创建项目** 后再选择本地或云端协作空间，创建位置不会被提前拆成两套入口。

在 Wework 中打开可执行的 Issue 时，详情页会显示 **本机助手**。它代表当前设备上的默认执行环境，会使用当前设备已经可用的模型、插件、Skill、本地文件和桌面能力。选择 **交给本机助手** 会打开任务输入框；发送要求后，实际运行会关联回当前 Issue，完成结果可以在 Issue 中查看和验收。

本机助手不是另一种需要单独创建的云端智能体，也不会把当前设备的账号、文件或系统权限同步到其他设备。需要稳定复用或共享特定提示词、插件、Skill 和 MCP 时，请创建智能体并明确配置其能力来源；设备专属能力仍以实际运行设备为准。

## 管理项目空间自动化

项目空间提供 **自动化** 管理入口，集中配置机器人成员并跟进执行队列。机器人可以成为项目任务负责人：被指派后自动领取任务，在本地或指定设备执行，并把执行结果或失败原因写回任务评论 Thread，提交结果供人工验收。

执行队列展示机器人任务的流转状态（待处理、排队中、已领取、执行中、失败待重试），并支持按关键词搜索任务。已完成的自动执行会以评论形式保留在任务详情中，人工可以基于评论验收，或要求机器人继续修改。

本地项目空间的机器人只能绑定本地或随行 App 设备执行；云端设备仅可用于云端项目空间的机器人。本地执行队列由本机 App 每 3 秒领取一次，执行中的任务会持续续租，任务异常中断后会在租约到期后自动重新排队，避免任务卡死在“执行中”。

### 在本机部署云端设备（开发测试用）

云端项目空间的机器人可以绑定云端设备执行。本地开发时，可以用仓库脚本把本机执行器注册成一个
`device_type=cloud` 的“云端设备”，从而在本机直接验证云端设备分发链路：

```bash
bash executor/scripts/dev-cloud-device.sh start    # 启动并保持在线（可重复执行）
bash executor/scripts/dev-cloud-device.sh status   # 查看运行与在线状态
bash executor/scripts/dev-cloud-device.sh restart  # 手动重启
bash executor/scripts/dev-cloud-device.sh stop     # 停止
```

- 默认设备 id 为 `cloud-device-dev`（可用 `DEVICE_ID` 覆盖），注册后出现在设备列表的“云端设备”中。
- 脚本会自动构建最新 executor，并持续监听 `executor/src`、`Cargo.toml` 和 `Cargo.lock`；
  源码变化后会增量编译并动态重启 executor。它还会从 `backend/.env` 读取密钥签发 30 天
  token，并使用独立的 executor home 与 Codex home（不读取个人 Codex 凭据）。
- 创建机器人时执行环境选择“云端”、执行设备选择 `cloud-device-dev`，指派任务后即在本机按
  云端设备协议执行并写回评论与执行记录。
- 运行数据与日志位于 `~/.wegent-executor-cloud-device/`。

## 选择模型和设备

模型决定任务使用的 AI 能力，设备决定代码和命令在哪里执行。本地模型只能用于本机设备；云端模型和设备需要先连接 Wegent。

任务输入框中的编码工具选择器用于选择 Codex、Claude Code 等本地运行时。目前任务输入框不提供直接选择云端 Wegent 智能体的入口；需要让云端智能体自动处理项目任务时，请在项目空间的 **自动化** 中配置机器人和执行环境。

打开输入区的模型选择器后，简版面板会分开显示账户来源、选择模式、当前模型和推理强度：

- **推荐模型集**：滑条的每个档位对应一组模型和推理强度，调整档位可能切换模型。其他模型集显示各自的名称。
- **固定模型**：手动选择具体模型后，滑条只调整该模型的推理强度。点击重置按钮可恢复默认推荐模型集。

点击模式或模型名称可打开完整模型列表，按本机 ChatGPT 账户、云端模型和自定义模型选择模型集或具体模型。长模型名称会完整换行显示；空间不足时面板可滚动。

模型、选择模式和推理强度按“新任务默认”和“当前任务设置”分开记忆。离开页面再返回时，固定模型仍保持固定，不会因其也属于推荐集而变成模型集模式：

- 没有打开任务时，输入区中的选择用于当前草稿和下一条新任务。独立任务会把该选择保存为后续新任务的默认值。
- 本地项目设置为“跟随全局”时，项目输入区中的选择会更新全局新任务默认值，后续独立任务和同样跟随全局的项目都会使用该选择。项目显式配置默认模型和推理强度时，输入区临时切换只影响本次任务；再次新建任务时会恢复项目默认。
- 任务启动后，模型和推理强度属于该任务。继续发送消息时会保存最新选择，切换到其他任务再返回时仍会恢复；它不会反向修改新任务默认或项目默认。

会话启动后仍可在官方 GPT/Codex 模型和第三方模型之间切换。选择不同模型时，Wework 会先显示确认提示；确认后，新模型从下一条消息开始生效。

如果已有上下文包含原 provider 生成的加密推理或压缩状态，executor 会在切换请求中自动移除这些不可移植字段，避免目标模型报 `invalid_encrypted_content`。普通消息、工具结果和其他可移植上下文会继续保留。

## 任务运行中的控制

侧边栏会保留运行中任务及其运行指示。收起或展开项目、展开或收起历史任务列表，都不会改变任务的运行状态。继续已有对话时，上一轮的完成状态不会结束当前正在执行的新一轮；当前轮次结束后，运行指示才会消失。

压缩上下文只有在压缩轮次成功结束后才显示完成。期间插件同步和仅在空闲时执行的进程重启会等待，压缩失败或中断不会显示为成功。
等待结果超时不表示压缩已经停止；仍在执行的压缩会保留运行保护，直到原生轮次结束。需要中断时可使用暂停操作。

启动请求尚未确认时，之前的完成快照不会清除运行指示；执行器确认开始执行后，当前轮次的完成状态会正常结束运行。

任务运行时有三种发送方式：

| 操作               | 快捷键                         | 适用场景                   |
| ------------------ | ------------------------------ | -------------------------- |
| 当前回复结束后发送 | `Enter`                        | 补充下一步要求             |
| 引导当前回复       | `Command/Ctrl + Enter`         | 调整正在进行的工作方向     |
| 打断并立即发送     | `Command/Ctrl + Shift + Enter` | 当前方向错误，需要马上停止 |

打断会停止当前回复，但已经完成的文件修改和命令不会自动回滚。

### 回答 AI 的提问

提问卡片会在回答框上方独立显示完整问题，长问题自动换行；内容过多时可在卡片内滚动查看。没有选项的问题也会保留题干，输入回答后仍可查看。请在标有“输入你的回答”的输入框中填写答案，再点击“提交”。

## 使用分身监督

在新的 Codex 对话或已有 Codex 任务输入区的 **+** 菜单中开启 **监督**。主 AI 工作期间，执行器会在后台定时读取最近的 AI 进展，并使用独立的只读轻量调用检查目标偏移、遗漏约束、破坏性操作和明显的阻塞循环。监督是正式功能，无需开启“实验性功能”；巡检不会 fork 原任务，也不依赖任务界面保持打开。

- **先建议**：在输入框上方显示纠正建议，由你决定是否发送。
- **自动纠正**：发现明确偏差时，运行中直接引导当前回复，空闲时像你在输入框发送要求一样开启后续回复。

监督配置属于当前任务。你可以单独指定巡检模型；巡检频率可选 10 秒、30 秒、1 分钟或 5 分钟。Wework 会在当前设备记住最近一次保存成功的巡检模型和频率，并在配置新任务监督时自动恢复。你还可以在“设置 → 上下文”中设置全局监督原则；首次开启任务监督时会自动带入，并允许针对该任务修改。

监督启动后，右侧 **环境** 面板会显示监督状态和下次巡检时间。选择 **立即巡检** 可以跳过等待时间并马上检查当前进展；正在巡检时该按钮会暂时禁用，避免同一任务并发执行多个监督检查。

## 查看处理过程

AI 回复中的“已处理”区域会按实际创建时间从上到下展示工具调用。即使执行器的事件到达顺序发生变化，较早创建的命令、文件操作或其他工具仍会显示在较早位置，便于按照真实执行过程阅读和排查任务。

已完成的处理活动会按类型汇总：终端命令和 Node.js REPL JavaScript 调用计入“命令”，MCP 等其他能力计入“工具”，文件读取和编辑则使用各自的分类。展开处理区域后，点击某一行或右侧箭头可以查看详情。折叠行使用便于阅读的短名称；详情中会显示完整工具名称、调用输入和返回输出。没有输入或输出的状态型活动不会显示无意义的展开按钮。

计划模式生成的计划属于回复主体，不会收进已完成回复的“已处理”折叠区域；恢复后台任务或重新打开会话后，计划也会保持直接可见。普通命令、文件操作和工具调用仍按上述规则汇总和折叠。

## 管理会话

任务可以继续对话、重命名、复制到其他设备或归档。项目会话显示在所属项目下；没有项目的会话显示在独立对话列表中。已归档会话可以在设置中恢复或删除。

右键已启动的任务，选择 **移动到项目**，可将其归入同设备上另一个可用项目。移动后保留原会话、历史记录和执行目录；重启后仍会显示在目标项目下。

### 导出会话

在会话顶部选择“导出会话”，或打开会话列表项的菜单，可以将当前完整会话导出为 Markdown 或 HTML。导出前可以选择正文、工具调用与文件修改、思考过程、图片和其他附件；HTML 中选中的工具调用、文件修改和思考过程默认折叠，便于优先阅读对话正文。

- **Markdown** 默认只选中正文，不默认选中图片。只导出文本时会生成 `.md` 文件；选中图片或其他附件时会生成 ZIP 包，其中 Markdown 使用相对路径引用包内资源。
- **HTML** 默认选中正文和图片。图片会嵌入 HTML，单个文件即可离线查看；选中需要独立保存的其他附件时会生成 ZIP 包。

选择保存位置后，导出窗口会持续显示打包和写入状态。只有后台导出任务完成并确认目标文件已写入后，窗口才会显示完成结果；覆盖已有文件时，写入失败不会删除原文件。

在一条已完成的 AI 回复下，将指针移到消息操作区并选择“在新任务中继续”，可以从该轮创建独立任务。新任务保留截至所选回复的对话上下文并使用同一工作区；原任务及该轮之后的消息不会被修改。正在生成、已取消或无法映射到 Codex 轮次的回复不显示此操作。

当你在消息底部切换到其他会话时，Wework 会保留“跟随最新消息”的状态。即使原会话在后台继续输出，切回后仍会显示最新内容；如果你在切换前主动向上滚动，Wework 则会恢复原来的阅读位置。
