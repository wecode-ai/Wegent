# 内置浏览器

Wework 内置浏览器位于右侧工作区，可在处理任务时查看网页、验证本地应用并把页面信息交给 AI。

## 打开网页

1. 打开右侧工作区的新标签页菜单。
2. 选择 **浏览器**。
3. 在地址栏输入 `http`、`https`、`file://` 地址或本机绝对路径。

浏览器会保留当前地址、标题和页面状态。切换到文件或审核标签页不会关闭网页。右侧工作区一次保留一个浏览器标签页。`file://` 地址和 `/Users/.../file.html` 这类本机绝对路径适合预览本机 HTML、PDF、图片和文本文件，也可以打开本机目录。Markdown、无扩展名的文本文件也会按文本预览。目录会显示为只读索引页，点击子目录可继续浏览，点击文件会进入对应预览；如果文件类型无法预览，Wework 会取消本地文件下载并弹出一个短暂提示。

顶部可以同时打开多个任务标签页，每个任务都拥有独立的内置浏览器页面。切换到其它任务后，原任务的浏览器会保持隐藏运行；该任务中的 AI 仍可继续打开、等待和检查页面，切回任务时会显示最新页面状态。浏览器页面不会跨任务共享。目前一个任务的右侧工作区仍只提供一个浏览器标签页，不提供浏览器内部的多标签栏。

编辑地址栏时，后台页面状态同步不会覆盖正在输入的地址。如果浏览器已经打开网页，未提交直接离开地址栏时会恢复当前页面的真实地址；如果尚未打开网页，未提交的地址会保留，并在切换会话后恢复。

Wework 弹窗、菜单或浮层与右侧浏览器区域重叠时，浏览器会暂时隐藏，避免原生网页遮挡主界面操作。关闭或移开浮层后，浏览器会自动恢复。

## HTTP 与证书提示

内置浏览器支持访问 `http` 地址，适合打开本机开发服务或受信任的内网系统。HTTP 不会加密传输内容，请勿在这类页面输入密码、令牌或其他敏感信息。

在 macOS 上，如果 `https` 页面使用过期、自签名、域名不匹配或其他无法通过系统信任校验的证书，Wework 会继续加载页面，并在地址栏下方持续显示证书风险提示。只有当前证书异常站点显示该提示；导航到其他来源后提示会清除。继续访问不代表连接安全，请先核对站点地址，并避免提交敏感信息。

## 页面批注

### 工具栏与更多菜单

| 功能点             | 界面步骤与结果                                                | 注意事项                                                       |
| ------------------ | ------------------------------------------------------------- | -------------------------------------------------------------- |
| 外部打开           | 浏览器工具栏 → 外部打开                                       | 交给系统浏览器；不会迁移内置浏览器登录状态                     |
| 页内查找           | 工具栏 … → 查找，输入词并切换匹配项                           | 查找当前网页，不搜索任务历史                                   |
| 设备模拟           | … → 设备工具栏 → 选预设或填写宽高；旋转、缩放；关闭工具栏退出 | 模拟视口，不会创建真实手机或切换执行设备                       |
| 历史记录           | … → 历史                                                      | 打开浏览历史管理                                               |
| 清理 Cookie / 缓存 | … → 对应清理操作                                              | Cookie 清理影响登录；缓存/存储清理影响网页数据，先保存网页工作 |
| 浏览器设置         | … → 浏览器设置                                                | 进入本页下方的设置控件                                         |
| 下载列表           | 工具栏 → 下载 → 找到记录 → 显示目录、暂停、恢复或删除         | 操作是否可用取决于下载状态；先核对记录再删除                   |

开启批注后，可以选择网页中的可见元素并输入评论。批注会作为当前消息的上下文发送，适合指出布局、样式或交互问题。

## 与 AI 一起使用

当任务启用了浏览器能力时，可以要求 AI 打开页面、检查内容或完成操作。AI 使用的是同一个右侧内置浏览器，不会另外打开外部 Chrome。

AI 可以执行的常见浏览器动作包括：

- 打开或跳转到网页。
- 检查页面结构，识别输入框、按钮、链接、下拉框、复选框和可见文本。
- 点击、输入、填写表单、按键、悬停、滚动、选择下拉项和勾选选项。
- 等待页面加载、文本出现或页面稳定。
- 截取当前浏览器页面，用于排查页面状态。

AI 检查页面时使用结构化 `inspect` 结果；`screenshot` 仍表示真实截图。结构化结果会包含元素的角色、名称、文本、值、位置、可见性和是否可操作等信息，因此模型可以更稳定地定位页面元素。

AI 操作浏览器时，右侧面板会显示 Agent 操作状态。用户可以暂停 AI 接管并在确认后恢复。涉及账号、发布、付款、删除数据或其它高风险操作时，应在执行前确认目标和影响。

### 浏览历史页逐项操作

<!-- ui-source: src/components/settings/BrowserHistoryPage.tsx -->

<a id="browser-history-controls"></a>

从 **浏览器工具栏 … → 历史**，或 **设置 → 集成 → 浏览器 → 浏览历史 → 管理** 进入。

| 操作         | 步骤与结果                                                             |
| ------------ | ---------------------------------------------------------------------- |
| 搜索         | 在上方搜索框输入关键词；没有匹配记录与读取失败会分别提示               |
| 按日期浏览   | 点击日期组标题折叠或展开，再点记录打开页面                             |
| 删除多条记录 | 勾选需要移除的记录，再点删除所选；不清除网页 Cookie，也不删除对话记录  |
| 查看更多     | 继续加载历史记录；初次加载失败用页面重试，后续分页失败用分页位置的重试 |

## 浏览器设置

<!-- ui-source: src/components/settings/BrowserSettingsPage.tsx -->

<a id="browser-controls"></a>

从 **左下角账户菜单 → 设置 → 集成 → 浏览器** 进入。

| 功能点                  | 具体操作                                 | 结果与注意事项                                                                               |
| ----------------------- | ---------------------------------------- | -------------------------------------------------------------------------------------------- |
| 完全控制                | 阅读风险说明后再切换开关                 | 允许 AI 操作内置浏览器，包括提交表单和修改、删除页面数据，无需逐次确认；只在接受该风险时启用 |
| 网页 URL 和链接打开目标 | 在下拉框选择内置或系统浏览器             | 决定普通网页链接在哪里打开，不切换执行设备                                                   |
| 本地 URL 打开目标       | 单独选择本地链接的打开方式               | 与普通 HTTP/HTTPS 链接偏好分别设置                                                           |
| 浏览历史                | 点击管理，在历史记录页打开或删除记录     | 历史不是任务对话记录；无需为查看历史清除浏览数据                                             |
| 浏览数据                | 点击清理，阅读确认弹窗后确认或取消       | 会退出已登录网站；先保存网页中未提交的内容                                                   |
| 下载 → 位置             | 点击更改并选目录；自定义目录旁可恢复默认 | 控制后续下载位置，不移动已有下载文件                                                         |
| 下载前询问保存位置      | 开启后再下载文件                         | 每次下载时选择位置；关闭则使用配置的下载目录                                                 |

浏览器工具栏中的返回、前进和刷新作用于当前任务的网页；地址栏输入后提交才导航。需要给 AI 指出页面元素时，开启批注、选择元素、填写意见，再回到输入区确认随消息发送。与网页重叠的弹窗关闭后，浏览器才重新显示。
