# 内置浏览器

Wework 内置浏览器位于右侧工作区，可在处理任务时查看网页、验证本地应用并把页面信息交给 AI。

## 打开网页

1. 打开右侧工作区的新标签页菜单。
2. 选择 **浏览器**。
3. 在地址栏输入 `http` 或 `https` 地址。

浏览器会保留当前地址、标题和页面状态。切换到文件或审核标签页不会关闭网页。右侧工作区一次保留一个浏览器标签页。

编辑地址栏时，后台页面状态同步不会覆盖正在输入的地址。如果浏览器已经打开网页，未提交直接离开地址栏时会恢复当前页面的真实地址；如果尚未打开网页，未提交的地址会保留，并在切换会话后恢复。

Wework 弹窗、菜单或浮层与右侧浏览器区域重叠时，浏览器会暂时隐藏，避免原生网页遮挡主界面操作。关闭或移开浮层后，浏览器会自动恢复。

## HTTP 与证书提示

内置浏览器支持访问 `http` 地址，适合打开本机开发服务或受信任的内网系统。HTTP 不会加密传输内容，请勿在这类页面输入密码、令牌或其他敏感信息。

在 macOS 上，如果 `https` 页面使用过期、自签名、域名不匹配或其他无法通过系统信任校验的证书，Wework 会继续加载页面，并在地址栏下方持续显示证书风险提示。只有当前证书异常站点显示该提示；导航到其他来源后提示会清除。继续访问不代表连接安全，请先核对站点地址，并避免提交敏感信息。

## 页面批注

开启批注后，可以选择网页中的可见元素并输入评论。批注会作为当前消息的上下文发送，适合指出布局、样式或交互问题。

## 与 AI 一起使用

当任务启用了浏览器能力时，可以要求 AI 打开页面、检查内容或完成操作。AI 使用的是同一个右侧内置浏览器，不会另外打开外部 Chrome。

AI 可以执行的常见浏览器动作包括：

- 打开或跳转到网页。
- 检查页面结构，识别输入框、按钮、链接、下拉框、复选框和可见文本。
- 点击、输入、填写表单、按键、悬停、滚动、选择下拉项和勾选选项。
- 等待页面加载、文本出现或页面稳定。
- 截取当前浏览器页面，用于排查页面状态。

AI 检查页面时使用结构化 `inspect` 结果；`screenshot` 仍表示真实截图。结构化结果会包含元素的角色、名称、文本、值、位置、可见性和是否可操作等信息，因此模型可以更稳定地定位页面元素。

AI 操作浏览器时，右侧面板会显示 Agent 操作状态。用户可以暂停 AI 接管并在确认后恢复。涉及账号、发布、付款、删除数据或其它高风险操作时，应在执行前确认目标和影响。

## 浏览器设置

在 **设置 → 浏览器** 中可以配置下载目录、查看浏览器数据位置和清理缓存。清理浏览器数据会退出已登录网站，操作前请保存网页中未提交的内容。
