# 模型设置

在 **设置 → 模型** 中管理任务使用的模型。

- **Codex 订阅**：开启本地订阅后使用本机 Codex 账号和模型。点击“查看模型”调整模型能力，点击“管理账号”登录或管理账号。更改本地订阅开关后需重启应用。
- **自定义模型**：点击“添加模型”，选择 DeepSeek 等服务商，输入 API Key 后点击“获取模型”，选择模型并保存。服务商地址已自动配置；列表中没有的模型可手动添加。
- **自定义接口**：在同一个服务商下拉列表末尾选择“自定义接口”，填写接口名称、API 协议、Base URL 和所需的 API Key，再获取或手动添加模型。
- **云端模型**：连接云端后查看服务端提供的模型。

已添加的模型按接口分组，同组模型共享地址和 Key。点击“编辑”修改共享配置；展开分组后，点击“编辑模型”修改上下文长度、最大输出长度、模型能力及协议与工具设置。最大输出长度以 token 为单位，必须为正整数；填写上下文长度时，最大输出长度必须小于它。留空使用运行时默认值。

Codex 任务未显式指定上下文长度时，使用模型 Catalog 配置的上下文大小。最大上下文和自动压缩阈值是独立设置：例如最大上下文为 500,000、有效上下文比例为 95%，且未设置自动压缩阈值时，可用窗口约为 475k，默认自动压缩阈值约为 450k。

当模型同时配置了最大输出时，Codex 的自动压缩点按可用输入预算（上下文减去最大输出）的 80% 计算；例如 1,048,576 上下文、96,000 最大输出时，可用输入预算约为 952.6k，自动压缩点约为 762.1k。

“设置 → 上下文”中的“上下文压缩阈值”（默认 75%）只控制上下文指示器何时显示手动压缩提示，不会修改 Codex 的自动压缩阈值。Codex 的自动压缩阈值由任务所用模型 Catalog 的上下文窗口、实际输出预算和模型配置共同决定；如果云端模型没有匹配到专用 Catalog，会使用通用 GPT 兼容配置提供能力元数据；模型配置的上下文窗口和最大输出仍会覆盖该 profile 的默认值，但受 Codex 的 Catalog 上限和压缩上限约束。

添加或编辑模型时，可在对话框底部点击“测试连接”，测试当前填写的连接及所选模型，无需先保存。编辑时 API Key 留空会使用已保存的 Key。测试会检查接口鉴权和工具调用；成功显示“连接正常”，失败可展开详情，修改配置后重新测试。测试不会修改已保存的配置。

取消编辑不会保存；放弃未保存的修改时会要求确认。删除接口同时移除它的模型，不会删除已有对话。

旧版本的本地模型配置会自动迁移，保留模型 ID 和能力参数。只有保存成功并确认运行时加载相同版本后，才清理旧配置；迁移失败时保留旧数据，可重试。

自动回复建议位于 **设置 → 通用 → AI 辅助**，详见[自动回复建议](reply-suggestions.md)。
