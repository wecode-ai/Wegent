# 自动回复建议

在 **设置 → 通用 → AI 辅助** 中开启“预测下一条回复”。预测继承当前 Codex 会话的模型，无需单独选择预测模型。

任务会话、临时聊天和项目活动会话中的 AI 回复完成后，空输入框会显示一条灰色回复建议。按 **Tab、右方向键或 Enter** 接受，将其变成可编辑草稿。这次按键只接受建议；确认内容后再按正常发送快捷键发送。建议可以编辑和撤销，也可以直接输入自己的回复。

已有草稿、附件、引用、自动补全菜单、中文输入法组合输入、运行中的会话或待处理交互时，不显示建议。模型可能返回没有建议；请求失败、超时或模型不可用时，正常聊天仍可继续。

同一轮次和模型配置的预测结果保存在本机，刷新、重启或重新打开任务会复用，不会重复消耗模型额度。“没有建议”、失败和已接受状态也会保留；完成新一轮对话或修改模型配置后才会重新预测。每个任务只保存最新结果，归档时保留，永久删除任务成功后同步清理；批量删除只清理实际删除成功的任务。

预测使用当前会话模型的额度。Wework 使用 Codex 的临时预测分支，继承原会话的历史、有效配置、指令和工具定义，再发送一条预测提示，并使用低推理强度生成建议。提示要求模型不调用工具或执行操作；预测结果不写入正式会话历史。开始新一轮、关闭功能或离开最后一个使用该会话的输入框时会取消旧预测。没有已完成 Codex 轮次的新会话不生成建议。

保留原会话的提示词前缀有利于复用模型服务的缓存，但实际缓存命中和费用取决于模型服务。预测仍会产生模型请求，不能保证零成本或总是比短上下文请求更便宜。Wework 内置 Codex 0.163.0-alpha.5，以支持预测分支协议。

生成期间，输入框工具栏会显示轻量的“正在生成建议…”提示。开始输入后隐藏提示；完成、取消或失败后提示消失。

预测会使用当前会话所选模型的最新认证信息，不会把密钥写入任务历史。请求失败或超时时，输入框下方会提示检查当前模型的连接和认证设置，正常聊天仍可继续。修复设置并完成下一轮回复后，会重新生成建议；模型明确返回没有建议时不会显示错误。

建议出现后，可以点击“接受建议 · Tab”或使用 Tab、右方向键、Enter 填入草稿，再编辑并发送。

在 Wework 输入 `/model` 或点击底部模型按钮会打开同一个模型选择器。菜单打开时隐藏建议，关闭后恢复，避免接受建议的按键与菜单操作冲突。
