# 自动回复建议

在 **设置 → 通用 → AI 辅助** 中开启“预测下一条回复”，开启后展开预测模型设置。默认选择“与任务相同”，使用当前任务模型，也可以指定独立模型。关闭后收起模型设置并保留选择；所选模型不可用时不生成建议。

任务会话、临时聊天和项目活动会话中的 AI 回复完成后，空输入框会显示一条灰色回复建议。按 **Tab、右方向键或 Enter** 接受，将其变成可编辑草稿。这次按键只接受建议；确认内容后再按正常发送快捷键发送。建议可以编辑和撤销，也可以直接输入自己的回复。

已有草稿、附件、引用、自动补全菜单、中文输入法组合输入、运行中的会话或待处理交互时，不显示建议。模型可能返回没有建议；请求失败、超时或模型不可用时，正常聊天仍可继续。重新进入会话会复用当前应用运行期间缓存的同轮次结果。

预测使用所选模型的额度，并把当前会话的目标及最近上下文发送给该模型。请求运行在不启用工具的临时会话中，不执行任务，也不写入正式会话历史。开始新一轮、关闭功能或更换预测模型时会取消旧预测。

生成期间，输入框工具栏会显示轻量的“正在生成建议…”提示。开始输入后隐藏提示；完成、取消或失败后提示消失。

建议出现后，可以点击“接受建议 · Tab”或使用 Tab、右方向键、Enter 填入草稿，再编辑并发送。“与任务相同”仅表示使用同一个模型；预测仍是独立的短上下文请求，不代表 fork 原会话或复用其提示词缓存。

在 Wework 输入 `/model` 或点击底部模型按钮会打开同一个模型选择器。菜单打开时隐藏建议，关闭后恢复，避免接受建议的按键与菜单操作冲突。
