# 界面导航与功能位置

不知道某个功能在哪里时，先从本页查找入口，再阅读对应使用指南。本页描述桌面主窗口；弹窗、窄窗口和不同操作系统的布局可能不同。这里的路径是点击顺序，不是需要输入的命令。

## 先认识界面

| 区域       | 在哪里           | 可以做什么                                                              |
| ---------- | ---------------- | ----------------------------------------------------------------------- |
| 左侧栏     | 主窗口左边       | 新建任务、搜索、打开项目与历史对话；底部账户菜单进入设置                |
| 顶部标签栏 | 主窗口上方       | 在任务、协作（项目空间）、智能体等已打开页面之间切换；右侧 + 新建标签页 |
| 对话区     | 任务页面中央     | 阅读回复、查看工具执行过程、处理需要确认的请求                          |
| 输入区     | 对话区下方       | 输入任务、添加附件、选择模型与权限、选择插件或 Skill                    |
| 右侧工作区 | 对话右边，可收起 | 文件、审核、内置浏览器及其他工作区标签                                  |
| 底部面板   | 对话下方，可收起 | 终端等辅助会话                                                          |
| 设置导航   | 打开设置后的左边 | 按个人、集成、编码、已归档分组选择设置页                                |

左侧栏隐藏时，可用默认快捷键 `Command+B` 恢复；右侧工作区使用 `Option+Command+B`，底部面板使用 `Command+J`。这些是 macOS 默认值；其他系统及修改过的快捷键以 **设置 → 快捷键** 为准。

## 常见问题：我要去哪里

会话内切换模型的确认与会话保留规则见[模型设置](./user-guide/model-settings.md#model-controls)。

克隆认证失败、执行环境设备错误或会话中的 Git 认证错误，可从原位置的 **配置 Git 账户** 进入当前云端 Web 设置；已有同域账户进入编辑，否则预填新增。桌面 **账户菜单 → 设置 → 编码 → 代码托管 → 设备 Git 配置** 负责手动同步，空账户时可单独确认清理。入口仅适用于 ClaudeCode 云端或远程设备；本机 Git / SSH 配置在本机处理，Web 地址未解析时不跳到 Backend。详见 [仓库访问配置与设备同步](./git-connections.md#device-git-configuration)。

需要反馈问题或导出运行日志时，打开任意 Wework 桌面页面右上角的 **反馈问题** 图标。插件、我的助理、已安排和设置页面都提供同一入口；任务页面还可以附加当前任务上下文。详见[获取帮助](./troubleshooting.md#getting-help)。

待回答的业务问题提供 **先聊聊** 入口：从任务问题卡片或 **待你处理** 的问题详情进入，会在原任务右侧栏打开讨论标签页，与浏览器、文件并列。用途与限制见[处理 AI 的提问](./workbench.md#ai-questions)。

忽略待办：**待你处理 → 条目右侧叉号（暂不处理）**；批量处理：**待你处理 → 左侧列表顶部 → 全部忽略**。仅本机归档，不代替作答或更改 Issue 状态；见[处理提问与项目待办](./workbench.md#ai-questions)。

原问题已处理但通知回复未发送时，**待你处理 → 左侧列表上方 → 未发送的回复** 保留可复制的文本，并提供 **丢弃此草稿**；见[处理 AI 的提问](./workbench.md#ai-questions)。

从侧栏的 **项目 → 新建项目 → 云端项目** 可在选择远程主机时添加设备，见[项目与工作区](./projects.md#add-device-from-project)。

从 **项目设置 → AI 团队** 编辑智能体定义；导入和手动创建使用相同入口与权限规则，见[智能体配置](./projects.md#agent-capabilities)。

## 设置入口速查

先点击 **左下角账户菜单 → 设置**，再按表中的分组和页面名称选择。macOS 默认快捷键为 `Command+,`。设置的“插件”页用于 Codex 插件运行配置，与侧栏的插件市场不同；“Runtime”也不是 Node.js 执行文件设置。

| 分组 → 页面         | 查找什么 / 显示条件                                                                   | 内部路由                                |
| ------------------- | ------------------------------------------------------------------------------------- | --------------------------------------- |
| 个人 → 通用         | 语言、功能模式、实验性功能、启动行为、任务运行、存储清理                              | `/settings`                             |
| 个人 → 云端连接     | Wegent 登录、连接与设备，见[设备与云端工作](./devices.md)                             | `/settings/connections`                 |
| 个人 → 外观         | 主题、背景                                                                            | `/settings/appearance`                  |
| 个人 → 上下文       | 个性与任务上下文偏好                                                                  | `/settings/personal/context`            |

## 找不到入口时

1. 先确认正在使用桌面主窗口，且左侧栏、右侧工作区或底部面板没有被收起。图标按钮可悬停查看名称。
2. 确认所在上下文：任务里的模型选择、项目空间里的项目设置和应用全局设置不是同一层级。
3. 检查 **设置 → 通用** 的功能模式与实验性功能。专注模式隐藏代码托管、工作树并关闭内置 Git 插件；实验性入口也可能被隐藏。不需要为查找普通功能开启完整访问权限。
4. 云端能力检查连接状态与设备在线情况；项目管理操作检查当前项目角色；插件能力检查是否安装、启用及完成对应应用授权。不要把入口不存在直接判断为未登录。
5. 查看 **关于** 中的版本，并说明系统、当前页面、目标功能及可见按钮。文档随应用版本提供；若仍无法对应，应报告文档缺口，不猜测菜单位置。

## 覆盖范围与更新

本页是功能位置索引，详细操作保留在链接的专题文档中，避免复制多份流程。设置页和注册式侧栏入口通过真实 DSH 声明校验双语条目、名称、分组及显示条件；新增、删除、改名需在同一变更中更新本页。

输入区、项目菜单、账户菜单等非注册式控件仍需代码审查人工核对，自动测试不能证明所有按钮均已覆盖，也不能证明运行中界面的实际布局。维护规则见仓库 `wework/AGENTS.md`。构建会将中英文文档复制进内置 wework-docs，已安装的旧版本不会因仓库文档更新而即时变化。

启动时出现恢复中心或本机服务提示时，操作入口与限制见[启动故障与恢复](./getting-started.md#startup-recovery)。
