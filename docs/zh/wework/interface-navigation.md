# 界面导航与功能位置

不知道某个功能在哪里时，先从本页查找入口，再阅读对应使用指南。本页描述桌面主窗口；弹窗、窄窗口和不同操作系统的布局可能不同。这里的路径是点击顺序，不是需要输入的命令。

iPhone 和 Android 的主页、搜索、设备筛选与会话入口见 [Wework 手机版](./mobile.md)。

手机文件入口：**会话页右上角更多 → 文件 / 更改**；有可访问的工作目录时可用。
回复中的文件链接、附件和展开后的变更路径也可直接打开预览。操作与限制见[移动端文件预览](./mobile-file-preview.md)。

手机项目与会话管理：主页 **Wework ▾ → 新建项目 / 已归档会话**；项目行 **… → 置顶、重命名、归档全部聊天、移除**；会话行**左滑 → 归档**，**长按 → 置顶、重命名、复制 ID、归档**。移除项目保留文件和会话；永久删除仅在已归档会话中确认执行。详见 [Wework 手机版](./mobile.md)。

## 先认识界面

| 区域       | 在哪里           | 可以做什么                                                              |
| ---------- | ---------------- | ----------------------------------------------------------------------- |
| 左侧栏     | 主窗口左边       | 新建任务、搜索、打开项目与历史对话；底部账户菜单进入设置                |
| 顶部标签栏 | 主窗口上方       | 在任务、协作（项目空间）、智能体等已打开页面之间切换；右侧 + 新建标签页 |
| 对话区     | 任务页面中央     | 阅读回复、查看工具执行过程、处理需要确认的请求                          |
| 输入区     | 对话区下方       | 输入任务、添加附件、选择模型与权限、选择插件或 Skill                    |
| 右侧工作区 | 对话右边，可收起 | 文件、审核、内置浏览器及其他工作区标签                                  |
| 底部面板   | 对话下方，可收起 | 终端等辅助会话                                                          |
| 设置导航   | 打开设置后的左边 | 按个人、集成、编码、已归档分组选择设置页                                |

左侧栏隐藏时，可用默认快捷键 `Command+B` 恢复；右侧工作区使用 `Option+Command+B`，底部面板使用 `Command+J`。这些是 macOS 默认值；其他系统及修改过的快捷键以 **设置 → 快捷键** 为准。

## 常见问题：我要去哪里

让 AI 在文档、代码托管等连接来源有变化时继续任务：在**任务输入区**描述等待条件，AI 使用工具订阅，输入区上方显示来源和等待状态，点击状态同一行的**等待条件**可查看详情，左侧任务栏也显示事件状态；持续目标也可等待事件。详见[让 AI 等待连接事件](./tasks.md#connection-event-waits)。

会话内切换模型的确认与会话保留规则见[模型设置](./user-guide/model-settings.md#model-controls)。

让手机或同账号的另一台电脑访问本机任务：从 **左侧栏底部账户菜单 → 设置 → 连接 → 允许远程访问本机任务** 打开开关。该入口仅在桌面客户端显示，默认关闭，修改后立即保存到当前电脑；其他设备不能修改此开关。读取失败时，错误旁提供 **重试**。远程访问时本机须保持运行并连接云端，关闭开关会撤销后续访问。详见[设备与远程访问](./devices.md)。

克隆认证失败、执行环境设备错误或会话中的 Git 认证错误，可从原位置的 **配置 Git 账户** 进入当前云端 Web 设置；已有同域账户进入编辑，否则预填新增。桌面 **账户菜单 → 设置 → 编码 → 代码托管 → 设备 Git 配置** 负责手动同步，空账户时可单独确认清理。入口仅适用于 ClaudeCode 云端或远程设备；本机 Git / SSH 配置在本机处理，Web 地址未解析时不跳到 Backend。详见 [仓库访问配置与设备同步](./git-connections.md#device-git-configuration)。

准备语音输入模型：**左下角账户菜单 → 设置 → 个人 → 通用 → 语音输入**。官方语音插件加载后显示，准备模型后回到任务输入框录音；见[语音输入模型](./settings.md#voice-input-model)。

需要反馈问题或导出运行日志时，打开任意 Wework 桌面页面右上角的 **反馈问题** 图标。插件、我的助理、已安排和设置页面都提供同一入口；任务页面还可以附加当前任务上下文。详见[获取帮助](./troubleshooting.md#getting-help)。

如果看到页面错误或启动失败界面，可在 **刷新页面** 旁选择 **复制调试信息**。详见[获取帮助](./troubleshooting.md#getting-help)。

待回答的业务问题提供 **先聊聊** 入口：从任务问题卡片或 **待你处理** 的问题详情进入，会在原任务右侧栏打开讨论标签页，与浏览器、文件并列。用途与限制见[处理 AI 的提问](./workbench.md#ai-questions)。

业务问题卡片底部的 **跳过** 对异步提问只隐藏卡片，不发送消息；对阻塞式提问则回传空答案，结束等待。**收起** 保留文字、附件草稿，稍后可展开回答。输入和附件操作见[回答 AI 的提问](./tasks.md#question-answers)。

忽略待办：**待你处理 → 条目右侧叉号（暂不处理）**；批量处理：**待你处理 → 左侧列表顶部 → 全部忽略**。仅本机归档，不代替作答或更改 Issue 状态；见[处理提问与项目待办](./workbench.md#ai-questions)。

原问题已处理但通知回复未发送时，**待你处理 → 左侧列表上方 → 未发送的回复** 保留可复制的文本，并提供 **丢弃此草稿**；见[处理 AI 的提问](./workbench.md#ai-questions)。

从侧栏的 **项目 → 新建项目 → 云端项目** 可在选择远程主机时添加设备，见[项目与工作区](./projects.md#add-device-from-project)。

Issue 详情的 **参与者 → +** 支持搜索多选，负责人选择器也可搜索非项目成员；确认后仅授予该 Issue 的管理权限，见[项目成员与 Issue 协作](./projects.md#project-controls)。

从 **项目设置 → AI 配置** 编辑智能体定义；项目 Maintainer 可以编辑项目内的非私有定义，共享源定义仍按原权限控制。导入和手动创建使用相同入口，分配设备冲突的排查步骤见[智能体配置](./projects.md#agent-capabilities)。

## 找不到入口时

1. 先确认正在使用桌面主窗口，且左侧栏、右侧工作区或底部面板没有被收起。图标按钮可悬停查看名称。
2. 确认所在上下文：任务里的模型选择、项目空间里的项目设置和应用全局设置不是同一层级。
3. 检查 **设置 → 通用** 的功能模式与实验性功能。专注模式隐藏代码托管、工作树并关闭内置 Git 插件；实验性入口也可能被隐藏。不需要为查找普通功能开启完整访问权限。
4. 云端能力检查连接状态与设备在线情况；项目管理操作检查当前项目角色；插件能力检查是否安装、启用及完成对应应用授权。不要把入口不存在直接判断为未登录。
5. 查看 **关于** 中的版本，并说明系统、当前页面、目标功能及可见按钮。文档随应用版本提供；若仍无法对应，应报告文档缺口，不猜测菜单位置。

## 覆盖范围与更新

本页是功能位置索引，详细操作保留在链接的专题文档中，避免复制多份流程。设置页和注册式侧栏入口通过真实 DSH 声明校验双语条目、名称、分组及显示条件；新增、删除、改名需在同一变更中更新本页。

输入区、项目菜单、账户菜单等非注册式控件仍需代码审查人工核对，自动测试不能证明所有按钮均已覆盖，也不能证明运行中界面的实际布局。维护规则见仓库 `wework/AGENTS.md`。构建会将中英文文档复制进内置 wework-docs，已安装的旧版本不会因仓库文档更新而即时变化。

启动时出现恢复中心或本机服务提示时，操作入口与限制见[启动故障与恢复](./getting-started.md#startup-recovery)。**检查 Codex 配置 → 重试** 在配置读取尚未完成或失败时可见，用于重新读取状态。

个人分组的 **… → 分组设置** 管理当前账户实际拥有的个人分组；项目标题及项目行右侧不再提供加号。见[项目入口](./projects.md#workspace-resource-controls)。

Issue 动态中的图片、Markdown 和文件链接可打开附件预览，失败后可重试并下载原文件。见[附件与文档预览](./projects.md#issue-resource-preview)。

默认执行设备与新建事项设备授权入口见[协作设备设置](./devices.md#collaboration-device-defaults)：**协作 → 协作管理 → 执行设备 → 个人默认执行环境**；**协作 → 新建事项 → 更多设置 → 运行环境（可选）→ 个人默认执行环境 → 保存个人默认设备** 明确保存个人偏好，关联项目时通过 **项目设备授权（立即生效）→ 选择或添加设备** 管理项目授权。创建弹窗左下角的 **更多设置** 用于配置状态、优先级和截止日期。参与者弹层、固定创建操作区和未保存修改保护见[独立事项](./projects.md#independent-issues)。

关联已有任务：**协作 → Issue 详情 → 关联任务 → 关联已有任务**，参见[项目与 Issue](./projects.md)。

从评论创建子事项：**协作 → Issue 详情 → 主评论底部操作栏 → 回复旁的创建子事项**。线程内回复保留独立入口，显示条件与步骤见[从评论创建子事项](./projects.md#comment-child-issues)。

从任务输入区上方点击 **分享为事项**，或在会话中选中文本后点击 **分享给他人**。点击附件行左侧的 **添加附件** 或 **+** 上传文件，用两侧箭头浏览附件，或从底部操作栏左侧打开 **更多设置**。详见[会话分享](./tasks.md#share-conversation-as-issue)。
