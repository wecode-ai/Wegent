# 项目 AI 管理者

“项目 AI 管理者”是旧版指南的称呼，不能据此在当前版本寻找“看板底部项目 AI”或“协作成员 → 项目管理者”。当前项目设置没有独立的项目管理者页，也不应假定每个项目自动启用了一个管理者。

## 当前界面中的对应操作

1. 打开 **顶部 + → 协作 → 项目 → 项目设置**。
2. 在 **AI 团队 → 智能体** 配置项目可用的智能体；在 **AI 团队 → 成员** 管理项目成员；在 **AI 团队 → 协作团队** 维护协作组织。
3. 需要事件触发时，进入当前项目可用的 **自动处理**，选择触发条件、执行对象及提示词后保存。该入口受项目能力及管理权限约束。
4. 需要对话时，使用看板右侧的 **会话**，或从具体 Issue 创建/打开关联任务；不要寻找旧的底部管理者 Composer。

参见[项目与工作区](./projects.md)、[看板自动化](./workbench.md)和[任务控制](./tasks.md#task-controls)。

## 操作边界

配置智能体或自动化不会扩大项目成员权限，也不替代工具确认。检查实际负责人与运行记录后再判断执行结果；保存规则、排队或等待人工处理均不代表任务已完成。旧版本的项目管理者内部字段或遗留提示文案不能证明当前界面存在该功能。
