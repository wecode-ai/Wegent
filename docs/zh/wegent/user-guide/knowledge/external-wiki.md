# 外部 Wiki 同步

将自建 Wiki.js 站点的页面绑定到知识库，作为同步文档参与 RAG 检索。绑定后系统每日自动检查远端页面版本，页面更新时自动重新拉取正文并重建索引，无需手动维护。

> **连接器支持范围**：目前仅支持 **Wiki.js 2.x，最低版本 2.5.300**。Wiki.js 3.x 及 2.5.300 之前的版本不在当前兼容矩阵内。

---

## 概览

外部 Wiki 功能由三部分组成：

| 组成 | 位置 | 说明 |
|------|------|------|
| **Wiki 连接** | 设置 → 集成 → 外部 Wiki | 保存 Wiki.js 站点地址和 API Key（加密存储在服务端） |
| **页面绑定** | 知识库 → 添加文档 → 外部 Wiki | 选择要同步的页面，每页生成一篇同步文档 |
| **每日同步** | 后台定时任务 | 自动比对远端版本，更新有变化的文档 |

与网页抓取的区别：网页抓取是一次性导入、手动刷新；外部 Wiki 是**持续绑定**——远端页面更新后自动同步，且同一页面重复绑定时复用原有文档，不会产生重复条目。

---

## 前置条件

- 拥有一个可访问的 **Wiki.js 2.5.300 或更高 2.x** 站点。
- 在 Wiki 管理后台 **Admin → API** 创建 API Key，权限组需包含：
  - `read:pages`（页面读取）
  - `read:source`（源码读取，缺少时无法读取页面正文）
  - `manage:pages`（Wiki.js 2.x 的 `single` / `singleByPath` resolver 会校验该权限；也可使用包含 `delete:pages` 的权限组）
- 环境开关 `EXTERNAL_DOC_SYNC_ENABLED` 已启用（默认启用）。关闭时绑定入口会提示"外部文档同步功能未启用"。

---

## 配置 Wiki 连接

1. 进入 **设置 → 集成**，找到 **外部 Wiki** 卡片。
2. 点击 **新连接**，填写：
   - **连接名称**：便于区分多个 Wiki 站点的显示名。
   - **连接器类型**：选择 Wiki.js（当前唯一选项；系统按可插拔连接器架构设计，后续版本将提供更多 Wiki 系统的连接器）。
   - **站点地址**：浏览器访问 Wiki 的根地址，例如 `https://wiki.mycompany.com`，不带 `/graphql`。
   - **API Key**：仅创建时展示一次，保存后加密存储；编辑时留空表示不修改。
   - **默认语言（可选）**：站点多语言时用于路径解析，如 `zh`。
3. 点击 **测试连通** 验证配置，返回"连接成功 + 版本号"即表示可用。
4. 点击 **保存**。

注意：

- 关闭**启用连接**开关后，系统停止远端页面读取和同步；已有绑定以及最近一次成功同步的本地正文和索引仍可使用。
- 删除连接前必须先解除所有引用该连接的同步文档，否则系统会拒绝删除并提示关联的知识库。
- 连接测试会执行页面列表、按路径解析和正文读取，而不只是检查网络连通；没有已发布页面且版本不可读时，连接测试不会判定成功。

---

## 绑定 Wiki 页面到知识库

1. 打开目标知识库，点击 **添加文档 → 外部 Wiki**。
2. 在 **Wiki 连接** 下拉框选择已配置的连接（未配置时会提示先到"设置 → 集成"创建）。
3. 在页面树中勾选要绑定的页面，支持：
   - 按标题或路径搜索；
   - 全选 / 取消全选；
   - 整目录选择（绑定该目录下的页面，不是递归绑定子目录下所有页面）。
   - 当站点页面数超过服务端浏览上限时，页面树会显示截断提示，仅展示最近更新的页面。
4. 点击 **绑定选中**。

绑定结果分三类提示：

| 结果 | 说明 |
|------|------|
| **已绑定 N 个** | 新绑定的页面，后台开始拉取正文并索引 |
| **已重新同步 N 个** | 之前已绑定的页面，本次触发了刷新 |
| **正在处理中，本次跳过** | 之前绑定的页面尚在索引流水线中，不会重复派发任务 |

绑定成功后，文档列表中会显示"同步 Wiki"标识，文档类型为"外部 Wiki"。

---

## 日常同步机制

绑定完成后无需人工干预，后台每日定时（默认 UTC 19:00，即北京时间凌晨 3:00）执行一轮巡检：

1. **扫描**：按批次遍历所有已绑定的 Wiki 文档（Redis 游标记录进度，单次最多处理 10000 篇，超时次日续扫）。
2. **探测**：通过 GraphQL 批量查询远端页面元数据（每批 500 页面一次请求）。
3. **比对**：比较远端版本（页面 `updatedAt`）与本地三个版本字段（观察版本 / 正文版本 / 索引版本）。
4. **更新决策**：

| 远端状态 | 系统行为 |
|----------|----------|
| 版本无变化 | 不做任何操作 |
| 页面内容有更新 | 重新拉取正文并重建索引 |
| 正文无变化但索引缺失 | 直接基于现有正文重建索引 |
| 页面已删除 | 见下节 |
| 连接不可用 / 权限失败 | 文档标记"同步失败"，保留现有内容，下轮自动重试 |

除自动巡检外，也可以在文档详情中手动触发**同步**，强制拉取最新正文（文档正在处理中时会提示稍后重试）。

---

## 源页面被删除怎么办

Wiki 页面被删除后，系统**不会删除本地文档**，而是将其标记为"Wiki 源文档不存在"：

- 已成功建立索引的文档**保留最近一次成功同步的索引内容**，Agent 仍可检索到删除前的内容。
- 状态会一直保持到页面恢复或手动解除绑定。
- 若源页面恢复（或权限恢复），下一轮巡检会自动检测到并恢复同步，无需重新绑定。

如确认不再需要该内容，在知识库文档列表中**解除绑定**即可，本地文档随之删除。

## 管理操作

| 操作 | 位置 | 说明 |
|------|------|------|
| 查看绑定列表 | 添加文档 → 外部 Wiki → 已绑定文档 | 显示路径、语言、页面更新时间、索引状态 |
| 解除绑定 | 已绑定文档 → 解除绑定 | 删除本地同步文档及其索引 |
| 手动同步 | 文档详情 → 同步 | 立即拉取最新正文并重建索引 |
| 停用连接 | 设置 → 集成 → 外部 Wiki | 停止远端读取和同步，绑定及最近一次成功同步的本地内容仍可使用 |
| 删除连接 | 设置 → 集成 → 外部 Wiki | 需先解除所有引用该连接的文档 |

### 权限要求

- 配置 Wiki 连接：任何登录用户管理**自己**的连接（连接与用户绑定，互不可见）。
- 绑定/解绑页面：需要目标知识库的**编辑权限**（创建者或管理员）。
- 同步文档与普通文档一致，遵循知识库的成员可见性。

## 常见问题

**Q：绑定后文档一直显示"排队中"？**
后台任务按队列执行，稍等片刻；超过 30 分钟未变化会被巡检任务标记为失败，可在详情中查看错误并重试。

**Q："Wiki 源文档不存在"和"同步失败"有什么区别？**
"Wiki 源文档不存在"表示远端 API 已确认页面不存在；"同步失败"表示本次检查或刷新未能完成，例如连接不可用或权限不足。两种状态都会保留最近一次成功同步的本地正文和索引；临时失败会在后续自动重试。

**Q：远端更新了，多久会同步到知识库？**
最迟下一次每日巡检（默认北京时间凌晨 3:00）。需要立即生效时对该文档手动执行**同步**。

**Q：同一个页面可以绑定到多个知识库吗？**
可以。每个知识库的绑定是独立的同步文档，各自维护索引。

## 服务端配置参考

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `EXTERNAL_DOC_SYNC_ENABLED` | `true` | 外部文档同步总开关 |
| `EXTERNAL_DOC_SYNC_CRON` | `0 19 * * *` | 巡检调度（UTC crontab） |
| `EXTERNAL_DOC_SYNC_SCAN_BATCH_SIZE` | `500` | 每批扫描的本地文档数 |
| `EXTERNAL_DOC_SYNC_RUN_MAX_DOCUMENTS` | `10000` | 单次运行最多处理文档数 |
| `EXTERNAL_DOC_SYNC_TIME_BUDGET_SECONDS` | `2700` | 单次运行时间预算（秒） |
| `WIKI_SYNC_REMOTE_BATCH_SIZE` | `500` | 每次 GraphQL 请求探测的页面数 |
| `WIKI_TREE_MAX_PAGES` | `5000` | 页面选择器最多加载的最近更新页面数，超出时显示截断提示 |
| `KNOWLEDGE_ATTACHMENT_ORPHAN_RETENTION_HOURS` | `24` | 知识文档孤儿附件删除前的安全保留时间 |
| `KNOWLEDGE_ATTACHMENT_ORPHAN_SCAN_BATCH_SIZE` | `200` | 每轮孤儿附件扫描上限 |
| `KNOWLEDGE_ATTACHMENT_ORPHAN_SCAN_INTERVAL_SECONDS` | `3600` | 孤儿附件扫描间隔（秒） |
