# 按优先级筛选任务

Wework 侧边栏顶部的铃铛按钮会临时切换到“优先级”视图，帮助您集中处理需要关注的本地运行时任务。它不会改变任务数据、项目结构或置顶状态。

## 打开和关闭

- 点击侧边栏顶部、搜索按钮右侧的铃铛按钮。
- macOS 使用 <kbd>⌥</kbd><kbd>⌘</kbd><kbd>U</kbd>；其他平台使用 <kbd>Ctrl</kbd><kbd>Alt</kbd><kbd>U</kbd>。
- 再次点击按钮或再次使用快捷键即可回到普通项目和任务列表。

筛选开启时，**新建任务**、**插件**、**已安排**、**应用**和云端连接等一级菜单仍会保留；只有项目与任务树会替换为跨项目的优先级结果。

## 哪些任务会显示

优先级视图按以下顺序显示任务：

1. 未读任务。
2. 等待您输入、审批或处理的任务。
3. 正在运行、生成或执行工具调用的任务。

没有上述状态的普通空闲任务不会显示。关闭筛选后，所有任务仍按原有项目和会话结构显示。

## 置顶会话

为避免置顶会话始终占据注意力，优先级视图默认不显示它们。将鼠标移到“优先级”标题上，打开选项菜单后可选择显示或隐藏置顶会话。此偏好会保存在当前 Wework 账户范围内。

## 通知图标

铃铛仅表示优先级筛选和“等待处理”状态。离开电脑 IM 提醒以及单个任务的 IM 订阅使用消息气泡图标，以免和优先级入口混淆。
