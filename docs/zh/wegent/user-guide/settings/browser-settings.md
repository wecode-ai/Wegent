# 浏览器设置

Wework 桌面版在 **设置 → 集成 → 浏览器** 中管理内置浏览器。Codex 浏览器工具控制的是当前任务右侧面板中同一个可见页面，不会另外打开 Chrome 窗口。

## AI 操作权限

**完全控制**默认关闭。开启后，AI 可以直接在本机所有任务的内置浏览器中执行操作，包括提交表单、修改或删除页面数据，不再逐次询问是否允许。设置保存在当前设备，重启后仍然生效。关闭后，后续需要授权的操作恢复确认；用户接管浏览器时，AI 仍会暂停操作。

## 链接打开位置

普通网页链接与本地开发链接可以分别选择打开位置：

- **系统默认浏览器**：交给操作系统设置的默认浏览器。
- **Wework**：在当前任务绑定的内置浏览器面板中打开。

如果当前没有可用的任务浏览器面板，Wework 会回退到系统默认浏览器，避免链接无响应。

本地链接包括 `localhost`、`*.localhost`、`127.0.0.0/8`、`0.0.0.0` 和 IPv6 回环地址。默认情况下，普通网页使用系统浏览器，本地开发链接使用 Wework。

## 浏览数据与隐私

在内置浏览器地址栏输入网页标题或部分网址，可以从候选列表打开访问过的页面。用上下方向键选中结果，再按回车打开。选择 **搜索网页** 会将输入的关键词交给 Google。要查看或删除访问记录，打开浏览器的 **更多 → 历史记录**。

内置浏览器使用独立于 Wework 主界面的数据存储。在设置中清除所有浏览数据会移除浏览和下载记录、Cookie、缓存和网站存储。已下载的文件和 Wework 应用登录状态会保留。

Wework 不读取或导入 Chrome 中保存的密码、联系信息和个人资料。需要使用现有 Chrome 登录态时，请把对应链接的打开位置设为系统默认浏览器。这个边界避免应用复制或另行保存浏览器凭据。

## 下载

下载默认保存到系统下载文件夹。可以选择自定义目录，也可以开启 **下载前询问保存位置**，让每次下载都显示系统保存对话框。

下载完成时，可以从提示中打开文件，或在系统文件管理器中显示它。要查看之前下载的文件，点击工具栏的下载图标或 **更多 → 下载**。列表显示文件名、状态、大小和时间。文件移走或删除后，记录仍然可见。下载过程中可以暂停或继续，暂停后可以删除任务和未完成文件。
