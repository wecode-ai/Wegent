# 桌面应用偏好

Wework 桌面版的“设置 → 通用”用于控制应用窗口和后台运行行为。这些偏好只影响本机桌面应用，不会改变云端任务、模型或执行器配置。

## 界面语言

“界面语言”用于切换 Wework 桌面界面和系统托盘菜单使用的语言。可以选择“系统”“中文”或“EN”。

选择“系统”时，Wework 会根据当前系统语言自动使用中文或英文。手动选择“中文”或“EN”后，Wework 会保存该偏好，并在下次启动时继续使用。

## 工作台背景

在 **设置 → 外观 → 工作台背景** 中，可以从本机选择 JPEG、PNG 或 WebP 图片作为界面背景。Wework 会把图片复制到本机应用数据目录，因此选择完成后移动或删除原文件不会影响背景。

默认情况下，只需选择一张图片并调整一组参数，浅色和暗色模式都会使用这套背景配置。开启“区分浅色与暗色模式”后，可以为两种模式分别设置背景图片、背景可见度、模糊度以及显示区域。首次开启时，两套配置会继承当前默认参数；之后关闭或重新开启该开关都不会清空默认配置或已经编辑的分模式配置。

“背景可见度”控制图片与主题底色的混合程度；设为 100 时显示清晰原图。“背景模糊”可在 0–20px 之间调整，默认 0。还可以分别控制背景是否覆盖主区域、侧边栏和顶部栏；设置界面的对应区域沿用相同选择。

启用顶部栏背景后，图片会连续显示在窗口控制区域后方，不会额外叠加实色顶部条。

主区域启用背景后，背景会连续覆盖对话区、右侧工作区和底部面板；对话输入框周围也不会额外覆盖不透明的底部渐变。

背景图片和这些外观偏好只保存在当前设备，不会上传或跨设备同步。“移除”只清理当前配置对应的托管图片；“恢复默认”会清理全部背景图片和背景偏好。

## 启动后是否显示主界面

开启“启动应用后显示主界面”后，启动 Wework 会自动打开主窗口。关闭后，应用启动时只进入系统托盘，适合希望开机后让任务能力常驻后台的用户。

当主界面未显示时，可以单击系统托盘图标重新打开窗口。

## 最大并行任务数与任务队列

在 **设置 → 通用 → 运行** 中，可以设置当前设备允许同时运行的最大任务数，范围为 1–20，默认值为 10。达到上限后，新任务不会立即请求模型，而是进入当前设备的等待队列。

排队任务会在任务列表中显示队列位置。可以将任务向前或向后移动；新的顺序会直接决定后续空闲执行槽位释放时的启动顺序。也可以选择“立即执行”，让指定任务临时突破并行上限开始运行。强制启动不会中断已经运行的任务；在超额运行的任务结束、实际运行数重新低于上限之前，其他排队任务不会继续启动。

等待队列由执行器在内存中调度，并将可恢复副本密封保存在当前设备的本地应用数据目录中。退出或重启 Wework 后，尚未启动的任务会按保存的顺序恢复。密封文件用于避免队列凭据以明文暴露并检测内容篡改；密钥同样保存在当前用户私有的应用数据目录中，因此它不用于抵御当前本机用户账号已经被攻破的情况。队列只属于当前设备，不会上传或同步到其他设备。

## 弹出窗口

“设置 → 通用 → 弹出窗口”用于配置独立于主界面的轻量输入窗口。默认全局快捷键为 `⌥⇧Space`；点击铅笔可以录制其他“修饰键 + 主键”组合，点击删除可以关闭全局快捷键。

Wework 启动后会在后台预热弹出窗口，因此首次显示和后续重新打开都会复用同一个 WebView。窗口不能调整大小；输入区域以外的可见表面可以拖动窗口，按 `Esc` 会隐藏窗口而不会激活主窗口。窗口外围的透明区域不接收鼠标事件，点击会继续传递给后面的应用。

开启“设置 → 通用 → 弹出窗口 → 系统拖拽面板”后，从其他应用拖动文件或文本时，当前屏幕顶部会显示紧凑操作面板。选择“创建新对话”会激活弹出窗口并把拖入内容加入新任务；关闭该选项后不会显示系统拖拽面板。

新任务默认不使用项目。可以从输入框底部的项目菜单选择项目，并通过更多菜单选择当前工作区或新工作树、切换分支和权限；之后重新打开弹出窗口时会保留用户最近一次选择。发送第一条消息后，输入窗口会展开为独立对话窗口。右上角的“在主窗口查看”会关闭弹出窗口，并在主窗口中打开当前任务；“新建消息”会返回新的输入状态。

弹出窗口创建的任务仍由本机执行设备运行，并会立即出现在已打开主窗口的任务列表中，无需手动刷新。弹出窗口与主窗口是两个原生窗口，隐藏或移动其中一个不会改变另一个窗口的位置。

## 托盘显示

“设置 → 通用 → 托盘显示”可以分别控制未读完成任务、进行中任务、Codex 额度和云端额度。开启“Codex 额度”后，只有本机 Codex 可用且成功读取到额度时，托盘图标右侧才会显示 5 小时和 7 天剩余额度；Codex 不可用时不会显示空额度占位。开启“云端额度”后，Wework 会在连接云端且成功读取到配额时，在托盘图标右侧显示配额来源的英文缩写（最多 5 个字母）和剩余值，例如 `AIGC -85.68`。

左下角额度菜单和设置项会显示配额来源的完整名称，例如 `AIGC额度`。额度使用率按已用值除以总额度计算，并保留负剩余值，用于明确提示额度已超出。托盘提示和设置菜单会明确标注这些数据分别属于 Codex 或云端配额来源。

## 从其他 AI 应用导入

“设置 → 通用 → 从其他 AI 应用导入工作内容”可以把本机其他编码应用中的兼容内容导入 Wework 独立的 Codex 目录。导入会覆盖目标目录中的同名文件，但不会删除来源应用中的内容。

- **Codex**：导入范围与 Wework 首次启动时的 Codex 迁移一致，包括配置、登录信息、全局指令、插件、Skills 和相关缓存。
- **Claude Code**：将 `~/.claude/CLAUDE.md` 作为 Codex 全局 `AGENTS.md` 导入，并导入 `~/.claude/skills/`。

第一期不导入项目列表、Claude Code 插件或历史会话。导入功能只在 Wework 桌面版中可用；如果来源目录不存在或没有可兼容内容，Wework 会保留弹窗并显示错误，可以修复来源内容后重试。

## 关闭窗口后后台运行

“关闭主窗口后继续在后台运行”默认开启。开启后，点击窗口关闭按钮不会退出 Wework；正在执行的任务会继续运行，应用会保留在系统托盘中。

第一次关闭主窗口时，Wework 会提示“关闭窗口后，后台可以继续执行任务”。用户可以选择保持打开，或确认转入后台。确认后，该说明不会在每次关闭时重复出现。

点击“转入后台”后，确认提示会立即关闭，主窗口随后进入系统托盘。如果原生窗口未能关闭，确认提示会重新显示，用户可以再次尝试。

关闭到后台时，Wework 会销毁主窗口的 WebView，以释放主界面相关资源；任务执行器不会因此停止。重新从托盘打开窗口时，Wework 会创建新的主窗口并恢复到当前任务状态。

如果没有打开会话，新创建的主窗口会显示固定在窗口范围内的任务启动页；只有进入会话后，消息内容区域才会按需滚动。

## 任务运行时阻止电脑休眠

“任务运行时阻止电脑休眠”默认开启。当至少有一个任务正在运行时，Wework 会阻止电脑因空闲自动进入系统休眠。关闭主窗口并进入系统托盘后，只要任务仍在运行，防休眠状态就会继续保持。

所有任务结束、失败或被中断后，Wework 会立即释放防休眠状态，并恢复操作系统原本的休眠策略。Wework 不会主动让电脑立即休眠，也不会修改系统的休眠时间设置。

在 macOS 上，Wework 使用与应用进程生命周期绑定的系统电源断言实现防休眠，不会启动常驻的 `caffeinate` 进程。即使 Wework 异常退出，macOS 也会自动释放该断言，不会留下继续阻止系统休眠的后台进程。

如果不希望 Wework 控制休眠，可以在“设置 → 通用”中关闭该选项。关闭选项会立即释放当前的防休眠状态；之后重新开启时，如果仍有任务在运行，Wework 会重新阻止空闲休眠。

## 锁屏后的界面恢复

在 macOS 上，如果 Wework 主窗口连续失去焦点超过 1 分钟，例如电脑长时间锁屏，窗口重新获得焦点时会检查 WebView 是否已经恢复绘制。正常恢复的界面不会重新加载；如果 WebView 在 5 秒内仍无法完成绘制回执，Wework 会自动重建主窗口，并保留原来的窗口位置、大小、最大化和全屏状态。

自动重建只影响界面进程，不会停止 Wework 主进程或本机任务执行器，正在运行的任务会继续执行。重建后会从持久化状态恢复当前任务；尚未发送且只保存在界面内存中的输入可能无法保留。

## 应用快照

在 macOS 桌面版中，**设置 → 集成 → 应用快照** 用于查看 Appshots 状态和配置快照声音。默认快捷键是 `⌘⇧2`。按下快捷键后，Wework 会截取当前最前面的应用窗口，并通过 macOS 辅助功能读取该窗口提供的文本（可能包括滚动区域外文本），然后把 PNG 和文本上下文一起添加到当前输入框附件中。

首次使用时，macOS 会请求“屏幕与系统录制”和“辅助功能”权限。前者用于截图，后者用于读取窗口文本。选择允许并重新启动 Wework 后，再按一次快捷键即可生成完整 Appshot。Wework 不会额外显示应用内授权弹窗；如果之前拒绝了权限，请在“应用快照”设置页查看权限状态，并点击对应的“打开系统设置”完成授权。

窗口文本取决于目标应用提供的辅助功能信息。部分应用和网页只暴露当前可见内容，因此不保证每个窗口都能提供完整的滚动区域外文本。

应用快照保存在本机 Wework attachment draft 目录下，只作为当前输入框附件使用；它不会自动上传到 Backend，除非用户随后发送包含该附件的消息。

“播放声音”开关控制 macOS 截图成功时是否播放系统声音。关闭后，Wework 仍会生成快照并添加到输入框。

## 退出应用

如果需要完全退出 Wework，可以从系统托盘菜单选择退出。退出应用会停止本机运行中的执行器进程。

如果关闭“关闭主窗口后继续在后台运行”，点击窗口关闭按钮会退出应用，而不是进入托盘后台。
