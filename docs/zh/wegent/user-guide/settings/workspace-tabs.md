# 工作台标签页

Wework 内置工作台采用与浏览器相似的两类标签页：

- **固定标签页**：每次启动 Wework 时自动创建，并始终排列在标签栏最前面。
- **普通标签页**：由用户通过标签栏旁的 **+** 临时创建，仅在当前会话中保留，重启后不恢复。

## 配置固定标签页

进入 **设置 → 通用 → 固定标签页**，可以：

1. 添加任务、工作空间视图、智能体或已经安装的智能工作台。
2. 调整固定标签页的顺序。
3. 选择一个固定标签页作为启动后默认打开的标签页。
4. 从固定列表中移除不需要自动打开的标签页。

固定标签页不可在标签栏中关闭。将某个标签页从固定列表移除后，它不会在下次启动时出现；当前会话中已经打开的页面不受影响。

## 从标签栏添加标签页

点击标签栏旁的 **+**，可以直接添加：

- 任务
- 工作空间视图
- 智能体
- 已安装的智能工作台
- 智能工作台管理页

从 **+** 添加的标签页默认是普通标签页。如果希望某个智能工作台每次启动时都可用，请在 **设置 → 通用 → 固定标签页** 中将它加入固定列表。

## 智能工作台启动行为

固定的智能工作台会随对应标签页自动启动。普通智能工作台只在用户打开该标签页时启动。安装完成后，智能工作台会立即出现在 **+** 菜单和固定标签页的添加列表中。
