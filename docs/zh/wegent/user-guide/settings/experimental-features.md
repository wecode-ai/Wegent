# Wework 实验性功能

Wework 可以隐藏仍在实验阶段、可能变化或不稳定的功能。实验性功能默认关闭，只有在当前设备上主动开启后才会显示。

## 开启实验性功能

1. 打开 Wework 桌面端的“设置”。
2. 进入“通用”。
3. 打开“实验性功能”开关。

设置会保存在当前设备上，并立即更新正在显示的界面。关闭开关后，实验性功能入口会再次隐藏。

目前 TODO、应用和云端项目空间属于实验性功能。默认情况下，Wework 左上角不显示 TODO 切换按钮，侧边栏也不显示“应用”入口，对话输入框的 @ 菜单中不会出现“项目空间”相关条目；开启实验性功能后，TODO 按钮会出现在 Wework 与应用切换按钮之间，“应用”入口会出现在侧边栏中，可通过“站点”和“小程序”两个标签页管理应用，@ 菜单中也可以通过“项目空间”引用云端项目。

关闭实验性功能时，任务输入框上方的“工作空间”下拉框和对话中的“工作空间”状态条会隐藏，顶部标签页也不会显示“工作空间”标签页。开启后这些入口会重新出现。
