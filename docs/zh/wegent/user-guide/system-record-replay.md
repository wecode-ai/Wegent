# 系统操作录制与回放

Wework 桌面版可以在 macOS 上录制鼠标点击、键盘按键、滚动操作以及对应的前台应用上下文，并在之后按原顺序回放。录制只保存在当前设备，不会同步到云端。

## 准备系统权限

打开左侧导航栏的 **录制回放**。首次使用时，需要在 macOS 系统设置中允许：

- **辅助功能**：用于读取操作目标并在回放时控制其他应用。
- **输入监控**：用于捕获全局鼠标、键盘和滚动事件。

权限卡片显示 **已允许** 后即可开始录制。如果辅助功能已允许但输入监控仍未允许，设置按钮会直接打开输入监控权限页面。修改权限后，macOS 可能要求重新启动 Wework。

## 录制系统操作

1. 输入便于识别的录制名称。
2. 选择 **开始录制**。
3. 切换到目标应用并完成需要保存的操作。
4. 返回 Wework，选择 **停止并保存**。

录制过程中，页面会显示已捕获的步骤数和当前应用。保存后，录制库会显示名称、创建时间、步骤数和涉及的应用数量。

## 回放和停止

在录制库中选择 **回放**。Wework 会按照录制时的相对顺序执行步骤，并显示当前步骤和应用。

选择 **停止回放** 可以立即取消正在执行的回放。回放完成或取消后，可以再次开始录制、重新回放或删除录制。退出 Wework 时，正在运行的录制或回放辅助进程也会一并停止。

## 安全限制

- 密码等敏感键盘输入不会保存。
- 检测到受保护或高风险的系统目标时，Wework 会暂停，而不会自动继续操作。
- 回放可能切换并操作其他应用。开始前请保存未完成的工作，并确认目标应用处于与录制时相近的状态。
- 删除录制会从当前设备的本地录制库中移除该记录。

## 故障排查

如果无法开始录制或回放：

1. 确认当前使用的是 macOS 桌面版；其他平台暂不支持。
2. 检查权限卡片是否同时显示辅助功能和输入监控已允许。
3. 在 macOS 系统设置中移除后重新添加 Wework 权限，并重新启动应用。
4. 如果某次操作失败，等待页面恢复到可操作状态后可以直接重试，无需重启 Wework。
