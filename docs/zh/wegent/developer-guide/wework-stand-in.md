# Wework 我的替身

项目页“新建 Issue”旁的“AI替身”打开快捷配置，左导“我的替身”提供按项目管理的列表。自动处理默认关闭，设备默认选择当前设备；关闭自动处理时仍可编辑和保存设置，用于手动委托。

“自动处理分配给我的任务”使用配置表单底部的复选框，与智能体、设备、工作区和补充要求一起编辑。勾选或取消勾选只修改草稿，点击“保存”后全部设置一起生效。保存后仅处理之后新分配的任务；关闭后正在执行的任务继续。保存期间禁止重复提交和修改；保存失败保留全部选择和草稿，显示错误并允许再次保存。表单外的列表和入口展示已经保存的自动处理状态。

取消、点击外部或按 Esc 丢弃本次全部未保存修改，包括自动处理选择。“复用其他项目配置”显示可访问项目名称和配置名称；默认配置省略配置名称，不展示内部数字 ID。选择后仅填入当前表单，保存后应用到当前项目，不会修改来源配置或自动开启处理。

配置是设备本地设置，保存在该 Executor 的 SQLite 中。云端项目可以选择本人已连接的云端设备，读取并修改那台设备的配置；不同设备的开关独立，切换设备时加载该设备的配置版本。无需联系旧设备即可在另一台设备配置替身，旧设备的设置保留。设备离线期间无法修改其配置，重新连接后可继续编辑。

运行配置按“智能体 → 设备 → 本地项目 → 工作区 → 模型”排列。可选择项目中已有的智能体，保留其提示词、技能、插件和 MCP 配置；未选择时使用通用助手。智能体固定的模型保持锁定，否则默认选中设备提供的默认模型。设备确定后只展示该设备可用的本地项目，工作区可使用当前目录或基于指定分支新建 Git 工作树。未指定本地项目时沿用项目现有环境。

模型目录加载期间保留模型选择入口，并暂停保存设置；目录就绪后将默认模型一并保存，避免重新打开时默认模型被视为未保存修改。自动处理复选框可在模型目录加载期间编辑，保存仍需等待执行环境与模型校验通过。

补充处理要求复用普通 composer，选填文字不会由占位内容替代。Goal 模式通过加号菜单开启；模型位于 composer 外的配置列表，保存和取消在同一行。手工新建 Issue 可选择“交给我的替身”，即使自动接单关闭也可主动执行；附件上传完成后才分配并启动替身。

模型选择复用公共目录转换与来源分组，本机 ChatGPT 账户、云端模型和自定义接口分别展示，同名模型保留各自的执行身份。斜杠菜单与任务 composer 使用相同的插件和 Skill 目录：按选定设备和工作目录读取，未指定目录时读取该设备的默认目录，不创建临时任务。插件市场与详情页统一在任务标签页打开，保留原协作标签页及其编辑状态。

数据结构支持同一项目、同一用户在同一设备保存多个独立替身，每个配置包含 `id`、`name`、`tags`、`agentId`、提示词、开关和独立版本。设置面板可选择同项目的已有配置进行引用；复用其他项目的配置时复制设置，目标项目中不可用的智能体需要重新选择。任务任意标签与配置的 `tags` 精确匹配时使用该替身；标签规则优先于不限定标签的默认配置。没有匹配规则时使用默认配置；多个标签规则同时匹配时不自动执行，并在 Executor 日志记录冲突，避免任意选择。

选定设备的 Executor 定期检查分配并调用手动创建任务使用的 `runtime.tasks.create`，沿用普通任务绑定、运行调度、会话与结果入口。不新增服务端替身 API、执行队列、全局设备绑定或自动切换。云端项目仍通过现有项目 API 获取分配；本地项目不要求云端连接。Executor 停止时不触发，重新启动后继续检查启用之后的分配。

每轮检查沿用普通任务的分配标识和已有关联，避免同一次分配在后续轮询中重复创建。普通任务创建不提供跨设备的原子去重：两台设备同时读取到尚未关联的同一分配时，仍可能各自创建任务；替身不新增服务端锁或队列。执行后由本人沿用既有流程检查、提交结果，不增加替身专属交付或审核规则。创建 RPC 失败时沿用手动流程撤销 Issue 绑定；已经记录的失败任务保留在现有任务入口供人工处理，不在每轮检查中反复启动。

## 协作通知中的处理反馈

协作通知直接读取现有 Runtime 执行列表，通过项目、Issue 和本次分配标识关联替身任务。已有分配通知内展示面具图标、处理中、等你回复、处理完毕或失败状态；没有分配通知的本地或手动执行，也能在协作通知中找到。点击任务标题进入对应执行会话，不重新派发任务。

通知按来源、事件和时间、任务正文、轻量操作组织，不再增加“新任务”标题。创建通知时直接保存真实分配人姓名或负责人智能体名称，列表直接读取通知，不跨表反查。没有姓名的通知省略分配人信息，直接展示任务标题和时间，不显示占位文案。替身接手后在同一条通知更新身份和状态。

处理区域可以直接补充要求、回复真实的 Runtime 问题，或重试失败的替身任务。普通补充输入在点击“回复”后展开；需要你回答的问题直接显示。快捷回复继续原会话；Runtime 拒绝发送时保留草稿并显示错误。问题选项沿用会话中的原始问题和请求标识，不根据结果文本猜测可执行操作。

完成、失败和需要回复时重新显示未读，并更新列表排序。桌面提醒遵循协作通知的设置，正在查看该执行时不重复弹出。状态和通知关联由桌面前端完成，不新增后端 API 或 Executor 协议。

替身状态的已读标记和桌面提醒去重记录按账号保存在当前设备，不跨设备同步；原有分配通知仍使用已有的已读接口。两类辅助记录各保留 90 天、最多 1000 条，在读取和写入时清理，过期清理不删除真实通知、任务或执行历史。

聚焦测试覆盖设备设置持久化与版本、多配置及标签规则、历史分配过滤、已有关联过滤、设备切换，以及侧栏状态合并和保存更新。桌面 `stand-in`、`stand-in-workspace`、`stand-in-cloud`、`stand-in-controls` 和 `stand-in-notifications` 场景均注册至现有 CI，仅替换模型响应；其余存储、任务执行、云端 API 和设备连接使用真实实现。

## 验证计划

使用隔离 Electron 实例和独立项目、账号、Executor 数据；云端场景额外启动真实后端、数据库和远端 Executor。每个检查点独立建立前置条件，结束后关闭替身并销毁测试环境。实际运行结果与失败修复证据记录在 PR 中。

| 场景       | 操作                                   | 预期                                       |
| ---------- | -------------------------------------- | ------------------------------------------ |
| 默认与取消 | 打开设置，修改提示词后取消             | 默认关闭且选择当前设备，修改不保存         |
| 独立保存   | 关闭自动处理时修改并保存设置           | 配置持久化，自动处理保持关闭               |
| 即时开关   | 使用已保存配置开启，再关闭并取消编辑   | 开关即时持久化，取消不撤销开关             |
| 待保存开启 | 修改配置后开启自动处理，再保存并开启   | 确认前保持关闭，确认后采用新配置           |
| 关闭留稿   | 开启时修改配置，关闭自动处理后继续编辑 | 仅关闭自动处理，草稿保留且版本更新         |
| 启用与重载 | 保存开关和提示词，重载窗口             | 睁眼图标、侧栏面具与选择蓝条保留           |
| 自动执行   | 启用后分配新任务，离开看板             | 普通 Runtime 任务完成，关联任务可查        |
| 排除与停用 | 检查历史、他人、未分配及停用后的任务   | 不触发，不改变任务负责人                   |
| 版本恢复   | 外部更新配置后保存旧草稿，重新打开     | 冲突提示保留草稿，重新打开读取新版本       |
| 智能体     | 选择项目智能体再分配任务               | 原智能体提示词与模型进入真实执行请求       |
| 标签路由   | 建立 review/docs 配置并分配带标签任务  | 各使用自己的配置；同时匹配两条规则时不执行 |
| 重复检查   | 编辑已处理任务并等待多轮轮询           | 同一次分配仅一个关联任务和模型请求         |
| 云端设备   | 选择云端 Executor 并重新打开设置       | 配置保存在所选设备，本地保持关闭           |
| 已有关联   | 另一设备启用相应标签规则并等待多轮检查 | 不重复创建已有关联的任务                   |
