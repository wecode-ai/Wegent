# Wework AI 分支名生成

Wework 的分支选择器可以根据当前输入内容或任务标题生成 Git 分支名。生成模型复用“友好任务标题”的模型配置；未配置或配置模型暂不可用时，使用当前任务模型。

生成请求通过 App IPC 的 `runtime.text.generate` 进入 Rust executor，并由 Codex app-server 执行。该请求具有以下约束：

- 强制使用 ephemeral 轮次，不创建 Wework 任务或工作空间关联。
- 关闭工具与深度思考，避免加载与短文本生成无关的上下文。
- 复用标题模型的身份、选项、认证、模型 catalog 和路由。
- 只返回完成轮次的文本；失败或未完成轮次返回明确的 IPC 错误。

生成期间，分支名输入框和创建按钮保持禁用，并显示生成状态。生成结果只回填输入框，用户确认或修改后再显式创建分支。
