# Wework 消息滚动验证

Wework 桌面端聊天列表使用虚拟滚动。发送消息后，最新的用户消息必须完整位于聊天滚动容器内；流式回复增长时，如果用户仍在底部则继续跟随，否则保留用户当前视口。

实现滚动行为时需要遵守以下约束：

- 末尾流式消息使用虚拟列表的正常测量路径，避免重复调用测量接口破坏底部锚点。
- 用户主动向上滚动后，后续消息高度变化不得把用户视口拉回旧消息位置。
- 回归测试必须在真实 Tauri 应用中发送消息，并检查用户消息元素的边界完全位于滚动容器边界内。

运行桌面回归测试：

```bash
cd wework
pnpm e2e:desktop:streaming-text
```

该场景使用真实后端请求，并由桌面 E2E harness 提供确定性的 SSE 响应流；不得通过跳过、mock 前端请求或放宽可见性断言来掩盖滚动回归。
