# 外部文档按知识库形成独立副本

同一外部文档可以进入多个知识库，每个知识库独立拥有一份副本；同一知识库内只对应一篇知识文档，首次导入创建，再次导入更新原文档，为未来自动更新复用相同身份。副本之间不共享权限、附件、索引或生命周期，跨知识库移动遇到同来源副本时明确拒绝。

为控制复杂度，副本更新复用现有单版本处理流程：保留 Wegent 名称和文件夹，处理中暂时不可检索，失败后在原记录重试，不建设双版本回退。预览独立于索引状态：有知识库访问权限且当前已保存的正文可读取时，即使索引处理中或失败也可预览；无正文的占位记录、附件缺失或正文不可读取时不能预览。预览只展示当前保存的副本，不保证历史版本回退。正在处理时不重复启动任务，批量结果区分新建、更新和处理中；更新及未来自动更新先使用首次导入者的来源授权。

该选择以重复存储和更新期间短暂不可检索为代价，换取清晰的知识库权限边界、稳定的文档身份和最小实现复杂度；不采用全局唯一文档、跨知识库共享快照或同库重复副本。
