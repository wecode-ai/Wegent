# WeWork 插件市场 - 组件库和样式规范

## 1. 设计原则

### 1.1 视觉风格
- **简洁明了**：采用卡片式设计，信息层次清晰
- **中文优先**：所有文本内容完全汉化，符合中国用户习惯
- **轻量交互**：使用悬停效果、圆角、阴影等轻量化视觉反馈
- **响应式布局**：支持不同屏幕尺寸自适应

### 1.2 色彩规范
```css
/* 主色调 */
--primary-color: #000000;        /* 主要文字、图标 */
--primary-hover: #1a1a1a;        /* 悬停状态 */
--secondary-color: #666666;      /* 次要文字 */
--border-color: #e5e5e5;         /* 边框颜色 */

/* 背景色 */
--bg-primary: #ffffff;           /* 主背景 */
--bg-secondary: #f7f7f7;         /* 次级背景 */
--bg-hover: #f0f0f0;             /* 悬停背景 */

/* 功能色 */
--success-color: #00c48c;        /* 成功/启用 */
--warning-color: #ff9800;        /* 警告 */
--error-color: #ff5252;          /* 错误 */
--info-color: #2196f3;           /* 信息/链接 */
```

### 1.3 间距规范
```css
--spacing-xs: 4px;
--spacing-sm: 8px;
--spacing-md: 12px;
--spacing-lg: 16px;
--spacing-xl: 24px;
--spacing-xxl: 32px;
```

### 1.4 圆角规范
```css
--radius-sm: 4px;
--radius-md: 8px;
--radius-lg: 12px;
--radius-xl: 16px;
```

## 2. 通用组件

### 2.1 插件卡片（Plugin Card）

#### 样式规范
```
┌────────────────────────────────────────────────┐
│ 🔵  GitHub                                  ▷  │
│     查看仓库、Issue、Pull Request 和          │
│     Actions，并在团队从自动化更改。            │
│                                                │
│     GitHub · v2.3.0 · 开发工具                │
└────────────────────────────────────────────────┘
```

#### 结构
- **尺寸**：宽度自适应（最小 320px），高度自适应内容
- **内边距**：16px
- **圆角**：12px
- **边框**：1px solid #e5e5e5
- **悬停效果**：边框变为 #d0d0d0，背景变为 #fafafa，添加阴影

#### 内容布局
1. **图标区域**（左上）：
   - 尺寸：40x40px
   - 圆角：8px
   
2. **右侧操作按钮**：
   - 播放图标 ▷（查看详情）或 +（添加）
   - 尺寸：32x32px
   - 悬停显示背景色

3. **标题**：
   - 字体：16px，加粗
   - 颜色：#000000
   - 行高：24px

4. **描述**：
   - 字体：14px，常规
   - 颜色：#666666
   - 行高：20px
   - 最多显示 2 行，超出显示省略号

5. **元信息标签**：
   - 字体：12px
   - 颜色：#999999
   - 格式：`发布者 · 版本号 · 分类`
   - 使用 · 分隔

#### React 组件示例
```jsx
<PluginCard
  icon="https://..."
  name="GitHub"
  description="查看仓库、Issue、Pull Request 和 Actions..."
  publisher="GitHub"
  version="v2.3.0"
  category="开发工具"
  installed={false}
  onClick={() => {}}
  onInstall={() => {}}
/>
```

## 4. 响应式布局

### 4.1 断点
```css
--breakpoint-sm: 640px;   /* 小屏幕 */
--breakpoint-md: 768px;   /* 中等屏幕 */
--breakpoint-lg: 1024px;  /* 大屏幕 */
--breakpoint-xl: 1280px;  /* 超大屏幕 */
```

### 4.2 插件卡片布局

- **大屏幕（≥1024px）**：3 列网格
- **中等屏幕（768px-1023px）**：2 列网格
- **小屏幕（<768px）**：1 列网格

### 4.3 间距调整

- **大屏幕**：卡片间距 24px
- **中等屏幕**：卡片间距 16px
- **小屏幕**：卡片间距 12px

## 5. 动画效果

### 5.1 过渡动画
```css
/* 通用过渡 */
transition: all 0.2s ease-in-out;

/* 悬停缩放 */
transform: scale(1.02);
transition: transform 0.2s ease-in-out;

/* 淡入淡出 */
opacity: 0 → 1;
transition: opacity 0.3s ease-in-out;
```

### 5.2 加载动画
- 骨架屏：卡片轮廓 + 脉冲动画
- 加载指示器：旋转圆圈

## 6. 可访问性（Accessibility）

### 6.1 键盘导航
- Tab：焦点移动
- Enter/Space：激活按钮
- Escape：关闭弹窗/面板
- 方向键：在列表中导航

### 6.2 焦点样式
```css
:focus-visible {
  outline: 2px solid #2196f3;
  outline-offset: 2px;
}
```

### 6.3 语义化标签
- 使用 `<button>` 而非 `<div>` 作为可点击元素
- 为图标按钮添加 `aria-label`
- 使用 `role` 属性标识组件角色

## 8. 组件库工具

### 8.1 推荐技术栈
- **UI 框架**：React 18+
- **样式方案**：Tailwind CSS / CSS Modules
- **组件库**：Radix UI（无样式基础组件）
- **图标库**：Lucide Icons / Heroicons

### 8.2 状态管理
- **本地状态**：React Hooks (useState, useReducer)
- **全局状态**：Zustand / Jotai
- **服务端状态**：TanStack Query

## 9. 性能优化

### 9.1 图片优化
- 插件图标：WebP 格式，尺寸 40x40px@2x
- 懒加载：使用 `loading="lazy"`
- 占位图：显示品牌首字母

### 9.2 列表虚拟化
- 当插件数量 > 50 时，使用虚拟滚动
- 推荐库：react-window / react-virtuoso

### 9.3 代码分割
- 路由级别分割：市场页、管理页、详情页
- 组件级别分割：大型弹窗、富文本编辑器
