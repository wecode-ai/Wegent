### 1.3 市场源 Tab 栏

```html
<div class="market-source-tabs">
  <div class="tabs-container">
    <button class="tab active">官方</button>
    <button class="tab">Wegent</button>
    <button class="tab">ModelScope</button>
    <button class="tab-add">+</button>
  </div>
  <div class="search-container">
    <input type="text" placeholder="搜索插件" />
    <icon>🔍</icon>
  </div>
</div>
```

**功能说明**：

1. **官方 Tab**：
   - 固定在第一位，不可删除、不可拖拽
   - 默认激活状态

2. **自定义市场 Tab**：
   - 用户添加的开源市场
   - 支持拖拽排序
   - 长按显示上下文菜单：重命名、删除

3. **[+] 按钮**：
   - 点击打开"添加插件市场"弹窗
   - 固定在右侧

4. **搜索框**：
   - 实时搜索当前 Tab 下的插件
   - 支持模糊匹配：名称、描述、标签

**交互细节**：
- Tab 切换时，保存当前滚动位置
- 切换后自动加载对应市场的插件列表
- 搜索框清空时，恢复全部插件显示

### 1.4 分类标签栏

```html
<div class="category-tabs">
  <button class="category active">全部</button>
  <button class="category">开发工具</button>
  <button class="category">企业平台</button>
  <button class="category">生产力</button>
  <button class="category">数据分析</button>
  <button class="category">设计工具</button>
</div>
```

**分类定义**：

| 分类名称 | 包含类型 | 示例 |
|---------|---------|------|
| 全部 | 所有插件 | - |
| 开发工具 | Git、CI/CD、代码审查 | GitHub、GitLab、Code Review |
| 企业平台 | CRM、项目管理、通讯 | 飞书、钉钉、Jira |
| 生产力 | 文档、笔记、日历 | Notion、Obsidian、Google Calendar |
| 数据分析 | BI、数据库、API | Looker、MySQL、Postman |
| 设计工具 | 设计、原型、素材 | Figma、Sketch、Unsplash |

**交互**：
- 点击分类筛选当前市场源下的插件
- 分类 + 搜索可叠加过滤
- 显示筛选结果数量（如"开发工具 (12)"）

**显示逻辑**：

3. 仅在"官方" Tab 和"全部"分类下显示

**卡片样式**：
- 2 列布局（大屏可显示 4 列）
- 显示简要信息：图标、名称、一行描述

### 1.7 插件卡片交互

#### 悬停效果
- 卡片边框高亮
- 显示阴影
- ▷ 图标变为实心

#### 点击行为
1. **点击卡片主体**：跳转到插件详情页
2. **点击右侧按钮**：
   - 未安装：显示 + 号，点击快速安装
   - 已安装：显示 ✓ 号，点击查看详情

#### 右键菜单
- 在新标签页打开
- 复制插件链接
- 分享插件

## 4. 响应式适配

### 4.1 桌面端（≥1024px）
- 插件卡片：3 列网格
- 侧边栏宽度：240px
- 主内容区最大宽度：1200px

### 4.2 平板端（768px-1023px）
- 插件卡片：2 列网格
- 侧边栏可折叠
- 搜索框宽度自适应

### 4.3 移动端（<768px）
- 插件卡片：1 列列表
- 侧边栏折叠为抽屉
- Tab 横向滚动
- 底部操作栏固定
