# WeWork 插件市场 - @ 创建插件交互规范

## 1. 概述

### 1.1 功能定位
@ 创建插件功能提供快速访问和创建插件的入口，用户通过在对话框输入 `@` 字符即可唤起插件快捷面板，实现插件的快速引用、创建和浏览。

### 1.2 参考来源
该功能参考 Codex 的 @ 交互模式，结合 WeWork 的产品特性进行本地化适配。

### 2.5 数据来源

#### 最近使用逻辑
```javascript
function getRecentPlugins(limit = 5) {
  // 1. 获取用户最近 30 天使用的插件
  const recentUsage = db.pluginUsage
    .where('userId', currentUser.id)
    .where('lastUsed', '>', Date.now() - 30 * 24 * 60 * 60 * 1000)
    .orderBy('lastUsed', 'desc')
    .limit(limit);
  
  // 2. 如果不足 limit 个，补充热门插件
  if (recentUsage.length < limit) {
    const popularPlugins = db.plugins
      .orderBy('installCount', 'desc')
      .limit(limit - recentUsage.length);
    
    return [...recentUsage, ...popularPlugins];
  }
  
  return recentUsage;
}
```

#### 使用记录更新
```javascript
function recordPluginUsage(pluginId) {
  db.pluginUsage.upsert({
    userId: currentUser.id,
    pluginId: pluginId,
    lastUsed: new Date(),
    count: db.raw('count + 1')
  });
}
```

## 4. 插件引用语法

### 4.1 基本引用

```
@GitHub 查看我的最新 PR
@企业GitLab 列出所有开放的合并请求
@微博API 搜索关键词"人工智能"
```

**解析逻辑**：
```javascript
function parsePluginReference(input) {
  const regex = /@(\S+)\s+(.*)/;
  const match = input.match(regex);
  
  if (match) {
    return {
      pluginName: match[1],
      query: match[2]
    };
  }
  
  return null;
}
```

---

### 4.2 多插件引用

```
@GitHub 和 @GitLab 对比一下两个平台的 Issue
```

**解析逻辑**：
```javascript
function parseMultiplePlugins(input) {
  const regex = /@(\S+)/g;
  const plugins = [];
  let match;
  
  while ((match = regex.exec(input)) !== null) {
    plugins.push(match[1]);
  }
  
  return {
    plugins: plugins,
    query: input.replace(regex, '').trim()
  };
}
```

---

### 4.3 插件参数

```
@GitHub repo:openai/gpt-3 查看最新提交
```

**解析逻辑**：
```javascript
function parsePluginParams(input) {
  const regex = /@(\S+)\s+([^\s]+:[\S]+)\s+(.*)/;
  const match = input.match(regex);
  
  if (match) {
    const params = {};
    const paramPairs = match[2].split(/\s+/);
    
    paramPairs.forEach(pair => {
      const [key, value] = pair.split(':');
      params[key] = value;
    });
    
    return {
      pluginName: match[1],
      params: params,
      query: match[3]
    };
  }
  
  return null;
}
```

function resolveAlias(input) {
  const alias = db.pluginAliases
    .where('userId', currentUser.id)
    .where('alias', input)

function recommendPlugins(userInput) {
  // 1. 提取关键词
  const keywords = extractKeywords(userInput);

  const matches = db.plugins

## 7. 技术实现

### 7.1 前端组件

```typescript
interface CommandPanelProps {
  visible: boolean;
  position: { x: number; y: number };
  onSelect: (plugin: Plugin) => void;
  onClose: () => void;
}

const CommandPanel: React.FC<CommandPanelProps> = ({
  visible,
  position,
  onSelect,
  onClose
}) => {
  const [query, setQuery] = useState('');
  const [plugins, setPlugins] = useState<Plugin[]>([]);
  const [selectedIndex, setSelectedIndex] = useState(0);
  
  useEffect(() => {
    if (visible) {
      loadRecentPlugins();
    }
  }, [visible]);
  
  useEffect(() => {
    if (query) {
      filterPlugins(query);
    } else {
      loadRecentPlugins();
    }
  }, [query]);
  
  const handleKeyDown = (e: KeyboardEvent) => {
    switch (e.key) {
      case 'ArrowDown':
        setSelectedIndex(i => (i + 1) % plugins.length);
        break;
      case 'ArrowUp':
        setSelectedIndex(i => (i - 1 + plugins.length) % plugins.length);
        break;
      case 'Enter':
        onSelect(plugins[selectedIndex]);
        break;
      case 'Escape':
        onClose();
        break;
    }
  };
  
  return visible ? (
    <div 
      className="command-panel"
      style={{ top: position.y, left: position.x }}
      onKeyDown={handleKeyDown}
    >
      {/* 面板内容 */}
    </div>
  ) : null;
};
```

### 7.2 输入框集成

```typescript
const ChatInput: React.FC = () => {
  const [input, setInput] = useState('');
  const [showPanel, setShowPanel] = useState(false);
  const [panelPosition, setPanelPosition] = useState({ x: 0, y: 0 });
  
  const handleInputChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    const value = e.target.value;
    setInput(value);
    
    // 检测 @ 字符
    if (value.endsWith('@')) {
      const rect = e.target.getBoundingClientRect();
      setPanelPosition({
        x: rect.left,
        y: rect.top - 10 // 面板显示在输入框上方
      });
      setShowPanel(true);
    } else if (!value.includes('@')) {
      setShowPanel(false);
    }
  };
  
  const handlePluginSelect = (plugin: Plugin) => {
    // 将 @ 替换为插件引用
    const newInput = input.replace(/@$/, `@${plugin.name} `);
    setInput(newInput);
    setShowPanel(false);
    
    // 记录使用
    recordPluginUsage(plugin.id);
  };
  
  return (
    <>
      <input
        value={input}
        onChange={handleInputChange}
        placeholder="输入消息，@ 提及插件..."
      />
      
      <CommandPanel
        visible={showPanel}
        position={panelPosition}
        onSelect={handlePluginSelect}
        onClose={() => setShowPanel(false)}
      />
    </>
  );
};
```
