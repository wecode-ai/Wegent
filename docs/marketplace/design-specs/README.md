## 🎯 关键设计决策

### 1. 统一插件概念
前端统一为"插件"，底层区分类型：
- Connector - 连接器
- MCP - Model Context Protocol
- Skill - 技能
- CLI - 命令行工具

### 2. 智能市场命名
从仓库地址自动生成显示名称：
```
openai/plugins              → "OpenAI"
modelscope/mcp-servers     → "ModelScope"
github/awesome-plugins     → "Awesome Plugins"
```

### 3. @ 快捷引用
在对话中快速引用插件：
```
@GitHub 查看最新 PR
@GitHub repo:openai/gpt-3 查看提交
```
