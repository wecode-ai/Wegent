# Filter Tasks by Priority

The bell button at the top of the Wework sidebar opens a temporary **Priority** view. It helps you focus on local runtime tasks that need attention without changing task data, project structure, or pinning.

## Open and close

- Click the bell to the right of the sidebar search button.
- On macOS, press <kbd>Option</kbd><kbd>Command</kbd><kbd>U</kbd>. On other platforms, press <kbd>Ctrl</kbd><kbd>Alt</kbd><kbd>U</kbd>.
- Click the button or use the shortcut a second time to return to the normal project and task lists.

The filter keeps primary navigation—such as **New Task**, **Plugins**, **Scheduled**, **Applications**, and cloud connection—available. Only the project and task tree is replaced with cross-project priority results.

## Which tasks are shown

The Priority view orders tasks as follows:

1. Unread tasks.
2. Tasks waiting for your input, approval, or attention.
3. Tasks that are running, generating, or executing tools.

Normal idle tasks are not included. Turning the filter off restores the original project and conversation structure.

## Pinned conversations

Pinned conversations are hidden from the Priority view by default so they do not permanently consume attention. Hover over the **Priority** heading and use its options menu to show or hide pinned conversations. This preference is stored for the current Wework account scope.

## Notification icons

The bell is reserved for priority filtering and the waiting-for-attention state. Away-from-computer IM reminders and per-task IM subscriptions use message-bubble icons so they are not confused with the Priority entry.
