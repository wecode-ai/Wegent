# Wework Experimental Features

Wework can hide features that are still experimental and may change or be unstable. Experimental features are off by default and appear only after you enable them on the current device.

## Enable experimental features

1. Open **Settings** in the Wework desktop app.
2. Go to **General**.
3. Turn on **Experimental features**.

The preference is saved on the current device and updates the visible interface immediately. Turning it off hides experimental feature entry points again.

TODO, Applications, and cloud project spaces are currently experimental features. By default, Wework does not show the TODO switcher button in the upper-left corner or the Applications entry in the sidebar, and the composer @ menu does not include the "Project Space" entries. After experimental features are enabled, the TODO button appears between the Wework and Apps switcher buttons, Applications appears in the sidebar with Sites and Mini Programs tabs, and the @ menu can reference cloud projects through the "Project Space" entry.
