# Architecture-governed logic

Each governed flow lives in one independently maintained Markdown file in this
directory. Documentation navigation is generated from those files and their
`sidebar_position`; do not duplicate a topic catalog on this page.

Before changing a flow, update its topic file's scope, connection graph,
sequence diagram, code ownership, and essential invariants, and confirm that the
path is complete before changing code. For a new flow, create the Chinese topic
file first and then its synchronized English file.

Detailed product prose remains in the existing developer guides. This directory
contains only reviewable architecture truth.
